# DNE42 uniform-floor target

Registered before DNE42 computation. Parent is DNE41, bae3aa15f5db9beb87feeddf36c33b6d03f9534a.

For the fixed authenticated 36-column packet, N is its original native matrix and G its paid original projected-source Gram. The critical uniform-floor target is rho=max(v*Gv/v*Nv), over nonzero real coefficient vectors. N is strictly positive by the inherited native certificate. A lower target endpoint is proved by an exact rational trial; an upper endpoint is proved by positive rational congruence of u N-G, including every mixed entry.

This target is basis invariant. A target certificate is conditional: it does not assert that the original infinite high restriction has lower bound u. The currently certified original high floor remains 289/500. Comparison failure below a target does not assert original Weil negativity. Source integration, actual inverse response, whole-aperture positivity, RH and Lean are not established by this stage.
