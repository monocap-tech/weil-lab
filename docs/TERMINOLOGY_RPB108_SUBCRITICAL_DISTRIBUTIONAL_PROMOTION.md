# RPB108 terminology: subcritical distributional null promotion

Date: 2026-10-07 UTC. Additive global/F4 definitions.

- Y_t is global Fourier H^t with norm squared integral (1+|xi|)^(2t)|hhat|^2; Y_-t is its distributional dual.
- A supported distributional native null solution has support in [-a,a] and satisfies m_a(D)g+p_g=0 on (-a,a). Its pole moments are compact-distribution pairings with cutoff exponentials. This definition does not presume L2 or a form-domain identity.
- Subcritical negative promotion is the conclusion that such a solution in Y_-sigma, 0<sigma<1/2, belongs to the existing canonical full-native K_a.
- Supercritical physical regularity means Y_alpha with 1/2<alpha<1. It refers to the unchanged global zero extension.
- Source order r means the actual positive moment sum |theta_q|^r |p_q(h)|^2, retaining every multiplicity copy and established normalization.
- Physical L2 orthogonal projection Pi_K is distinct from the logarithmic Riesz operator or an effective-background/source projection.
