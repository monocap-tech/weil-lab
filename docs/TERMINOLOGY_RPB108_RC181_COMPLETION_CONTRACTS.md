# RC181 terminology: precision, coverage, and acceptance

- **Source-map action accuracy:** ||(M S-V)c||_D^2 <= beta c*G_lower c on a named family S. The relative norm upper is sqrt(beta). This is not a whole-domain operator approximation bound unless such coverage is separately proved.
- **Inverse-response width:** Sigma_upper-Sigma_lower <= beta G_lower. A width and an action norm error are different measurements. The midpoint response error is at most half the width in Loewner order, not a vector inverse error.
- **Acceptance ratio:** a certified error or width upper divided by a positive, explicitly selected acceptance threshold in the same metric. A ratio below one proves that contract only when its coverage requirements also hold.
- **Guaranteed margin:** the required threshold minus the certified uncertainty upper. For the half-Gram inverse contract, the gate matrix is at least this margin times the source Gram lower. It is not an original Weil spectral floor.
- **Coverage:** the operator, domain, source family, parity, all omitted tails, and mixed couplings to which a certificate applies. A finite frame and full native-frame coverage do not by themselves identify the original augmentation source range.
- **Comparable precision rows:** the same target operator, domain, norm, source map, and normalization. Changing the inverse trial basis can preserve comparability; expanding the response source family usually changes it.
- **Unset acceptance ratio:** null when the numerical theorem threshold or certified margin is missing. It is not zero, a failure, or an estimated completion percentage.
- **Local psi regular contract:** a chosen 1% relative D-norm error budget for approximating D^-1 R psi0 by zero. It is a component construction contract, not the accuracy requirement for the complete canonical action or Stage I.
- **Canonical psi source form:** psi0 + RC154's Cpsi generator - r D^-1 psi0, with exact analytic negative-r coefficients. Its complete error includes both the inherited endpoint error and the new regular component bound.
- **Historical preservation:** new dashboard entries add scope-aware facts. Historical checkpoint wording and certificates remain unchanged. No aggregate completion percentage is assigned.
