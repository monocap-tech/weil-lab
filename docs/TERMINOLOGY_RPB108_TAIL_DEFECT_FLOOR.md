# RPB108 supported tail-defect floor (NF66)

| Term | Meaning |
| --- | --- |
| Defect Delta_(N,m) | ORIGINAL Q minus NF65's even-m repaired lower form, with all original primes and both pole slots unchanged. A positive bounded physical Fourier multiplier. |
| Positive remainder kernel E_m(t) | 2t^(2m+1) sum_(n>=1) 1/{[(2pi n)^2]^m[(2pi n)^2+t^2]}; for even m, R_N-S_m is its nonnegative Laplace integral. |
| Aperture cap B | Any fixed finite B>0 with h supported in [-B,B]. It need not be a certified-positive window. |
| Translation steps k_B | ceil(4B), used for the t in [1,1+1/q] estimate. This analytic ceiling is not a prime-power threshold or a discontinuity of the original form. |
| Supported defect floor kappa_(N,m,B) | 2/{3^ceil(q+1) q 64^m [64+(1+1/q)^2] k_B^2}, q=N+1/4; a strictly positive physical-mass lower bound for Delta at even m. |
| Auxiliary comparison source gain | Analysis using complete ORIGINAL positive P and negative (N,Delta^(1/2)); the auxiliary channel is explicitly not an actual divisor row. |
| Relative defect | Delta(h)/Q_original(h) on original-positive vectors. An absolute physical error budget does not bound this ratio near a closing original gap. |
| Earlier comparison failure | Conditional on a finite ORIGINAL first contact, the fixed repaired lower form has negative vectors at apertures strictly below that contact. No original contact is asserted to exist. |

Proof and custody: [NF66 note](../notes/REFLECTED_PACKET_BRIDGE_108_TAIL_DEFECT_FLOOR_20261008.md). The original gain, the bare-cutoff compact gain and the auxiliary repaired gain remain distinct.
