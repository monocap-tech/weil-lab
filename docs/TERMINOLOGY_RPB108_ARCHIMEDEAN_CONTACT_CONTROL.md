# RPB108: shifted archimedean contact control

Registered: 2026-10-06 before the associated obstruction argument.
Pinned source: 42b2abf9985a4eeede2ab2e781d77c5114f98b0e.

The control uses the actual quarter-line symbol
  m0(xi)=Re psi(1/4+i pi xi)-log pi,
and its actual exterior kernel k(s)=exp(-s/2)/(1-exp(-2s)).
On D_a define E0(h)=integral m0 |Fourier(h)|^2 and
  lambda_a=inf {E0(h): h in D_a, ||h||_2=1}.
The shifted archimedean contact form is
  Qcontrol_a(h)=E0(h)-lambda_a||h||_2^2.
Its full interior null equation is (m0(D)-lambda_a)h=0 on (-a,a).

This is a comparison form with an explicitly tunable scalar mass. It is not the full actual zeta form: the prescribed finite prime terms and actual Hermitian pole are not present. No actual-zeta endpoint or RH counterexample is asserted.

Its physical vector is always the same global zero extension. The control's logarithmic Riesz operator and kernel use D_a; no bounded unrestricted L2 multiplier is inferred.
