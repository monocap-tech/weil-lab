# RPB-108 exterior residual supplement

Registered before first load-bearing use, 2026-10-01.

- **Exterior residual candidate**: the actual archimedean gap function minus
  the actual right-limit finite prime function plus the named source pole,
  restricted to the complement of the strict enlarged interval and extended
  by zero inside it. This constructs a function, not a source realization.
- **Central reconstruction attachment**: proof that this zero continuation
  represents the pole-restored source distribution. Vanishing by definition
  does not establish cancellation of the actual source action.

Terms are additive; Fourier normalization, source cancellation and the compact
weak identity remain separate obligations.
