# RPB108 normalization-compatible selection transport

Registered 2026-10-06 (America/Los_Angeles), before load-bearing use.

- **Physical null transport**: change the finite actual selection while retaining exactly k in the same physical support/domain. It does not enlarge support.
- **Selected metric on K**: b_R(h,g)=<Rh,Rg> for the full native kernel K.
- **Coefficient transport**: the unique map between finite defect kernels obtained by reconstructing the physical vector and taking its new selected samples.
- **Eligible source block for k**: an unselected allowed coordinate block every one of whose actual weighted rows vanishes on k. A required partner closure is part of the block; vanishing of only one partner is insufficient.
- **Eligible analysis Z_k**: the complete negative analysis restricted to the union of all eligible blocks; the original source metric is unchanged.
- **Blind kernel N**: K intersect ker R for the prescribed selection. Its normalization-compatible finite repair gate is N intersect ker Z_k={0}.
- **Normalization**: the retained total positive-plus-negative coefficient norm, not physical L2 normalization. Unit gain forces its square to be 2||Rk||^2.

These terms do not identify a fresh packet with a historical one. Named carrier, covariance, row, filtration and arithmetic custody remain separate.
