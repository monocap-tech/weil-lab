# RPB108 local transverse gate terminology

CC30, 2026-10-08. Original complete source coordinates and multiplicities.

- **Unit-height transverse mass:** S2(T)=sum beta_q^2 over every source
  copy with T<=theta_q<T+1, T>0. Here beta_q=Re(rho_q)-1/2.
  A fixed duplication convention changes constants, not the limit below.
- **Local transverse vanishing:** S2(T)/log T -> 0 as real T -> infinity.
  This is an every-height statement, not an average or density-one result.
- **Far-right local count:** R_epsilon(T) counts actual zeros with
  Re(rho)>1/2+epsilon in a unit-height window, with multiplicities.
- **Backlund criterion:** R_epsilon(T)=o(log T) for every fixed epsilon>0;
  this is equivalent to the Lindelof hypothesis. It is an imported classical
  theorem, not an unconditional arithmetic estimate established here.
- **Sparse cluster control:** an artificial reflected location dictionary
  with fixed transverse displacement, logarithmically many copies at very
  sparse heights. It tests location-count implications only; it does not
  satisfy the actual native Weil identity.

Local transverse vanishing is equivalent to the Backlund criterion using
the unconditional O(log T) total unit-height count and functional symmetry.
This equivalence is not a necessary condition for every conceivable shell
proof, and is not asserted equivalent to RH or to the CC29 covariance target.
