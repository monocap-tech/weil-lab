# RPB-108 finite Gauss convolution supplement

Registered before first load-bearing use, 2026-10-01.

- **Finite Gauss convolution**: convolution of the actual rough compact
  carrier with the complex-valued positive finite geometric Gauss kernel.
  Its negative is the finite term subtracted from the shifted digamma tail.
- **Finite weak Fourier transfer**: equality of its pairing with an arbitrary
  Schwartz test and the inverse-Fourier test pairing with the exact finite
  reciprocal symbol times the actual carrier Fourier transform.

This does not mean the infinite Gauss kernel is integrable, the shifted tail
vanishes as an operator, or the archimedean source has been represented.
