# RPB108: signed height limit nonuniformity

Additive definitions, 2026-10-07. Retain the original B_T finite signed height pairing from MIXED_HEIGHT_COMPENSATION and the positive canonical logarithmic norm ||.||_D. Its bounded Hermitian form norm is

    N_a(T)=sup_(||f||_D=||g||_D=1) |B_T(f,g)|.

For each finite T this equals the norm of its canonical Riesz operator and the supremum of |B_T(f,f)| on the unit sphere. It is not a physical-L2 operator norm or a kernel trace.

A modulated core packet is f_N(x)=exp(-i N x)psi(x), with fixed nonzero psi smooth and compact in the same open window. Its Fourier observations are centered at actual ordinate +N. Modulation changes the vector and does not assume a native null equation.

Smooth approximation of a fixed h means v_j in the same-window smooth compact core converging to h in the canonical D norm. Limits in j and in height T are separately defined; no joint or diagonal estimate is implied.
