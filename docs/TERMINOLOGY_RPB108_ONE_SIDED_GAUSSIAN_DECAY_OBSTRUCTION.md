# RPB108 terminology: one-sided Gaussian decay obstruction

- **One-sided exponential Fourier mass:** finite integral of exp(kappa xi)|Fourier(h)(xi)|^2 on xi>=0 for some kappa>0; no negative-frequency or reality premise.
- **Eventual exponential Gaussian upper bound:** M_R<=C exp(-delta R) for every sufficiently large real R, delta>0. A sparse subsequence is insufficient.
- **Endpoint-null-to-upper-estimate input:** independent derivation, from lawful actual endpoint nullity, of an eventual polynomial-times-exponential upper bound on the genuine action of the same vector against its moving Gaussian. Larger-window nullity is not implicit.
- **Gaussian-upper-bound-to-zero implication:** the analytic theorem combining that upper estimate with native Gaussian coercivity, Tonelli and the logarithmic-integral obstruction to give h=0. This implication is proved; the endpoint-null-to-upper-estimate input remains unproved.
