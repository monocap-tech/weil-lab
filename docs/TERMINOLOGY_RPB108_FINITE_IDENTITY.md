# RPB108 finite identity rigidity (CC25)

Use the original normalized pair profiles p_q(h)=integral h exp(i theta_q x)cosh(beta_q x), n_q(h)=integral h exp(i theta_q x)sinh(beta_q x). All multiplicity copies and partners remain.

| Term | Definition |
| --- | --- |
| Fixed native form | The SAME archimedean-minus-prime form and both signed pole pairings on the same supported canonical domain. |
| Legal finite alteration | A finitely supported signed difference of divisor multiplicities, preserving beta reflection at fixed theta and ordinate conjugation. It need not be arithmetically realizable. |
| Finite difference kernel | K(u)=sum_q c_q exp(i theta_q u)cosh(beta_q u), an entire exponential polynomial. |
| Effective exponential atoms | Distinct rates lambda=beta+i theta with coefficients after grouping. With beta-reflection symmetry these are exactly the grouped changed multiplicities. |
| Local exact rigidity | Equality of the COMPLETE mixed source forms for all smooth compact tests in any nonempty open aperture forces every finite changed multiplicity to vanish. |
| Stability distinction | Exact uniqueness does not give a uniform coefficient-recovery bound for approximate moment or form data when distinct atoms can coalesce. |
| Full physical mass | mu<h,f>_L2, the infinite physical identity channel in a shifted form; it is not a finite exponential kernel. |

The rigidity statement requires complete mixed-form equality. It does not assert that a critical-line replacement has the same actual native form, and cannot be used as such a premise in an RH argument.
