# CC58 terminology: compensated arithmetic correlation

Definitions precede the CC58 report; all previous terminology remains unchanged.

**Compensated tail row.** In one physical Legendre parity, with retained E, measured high H2, mixed block B and high block C2, let q_nE and q_nH denote the complete original signed Weil pairings of e_n with these bases. For an unmeasured high index n define r_n=q_nE-q_nH C2^{-1}B*. This is a row on E, not a scalar eigenvector phase.

**Compensated physical correlation.** The matrix K=sum_n r_n* r_n over ALL unmeasured high indices equals the physical residual Gram P2. A finite partial sum is a lower bound, not an upper-tail certificate. Its existence follows from physical L2 representability of the finite compensated polynomials and Parseval.

**Certified source radius.** For an approximate compensated high-source map Rhat and exact map R, eta is a certified operator bound ||R-Rhat||<=eta from physical E to the high L2 space. A stronger source-aligned radius delta bounds ||(R-Rhat)S2^{-1/2}||, where S2=A-BC2^{-1}B*>0. Merely having finite source coefficients gives neither radius nor a tail rate.

**Young majorant.** For every rational t>0, K<= (1+t)Rhat*Rhat+(1+1/t)eta² I. Comparing this matrix with kappa S2 gives a rigorous sufficient positivity gate without subtracting S2² from a source-square enclosure.

**Sector completion control.** An abstract test changes an omitted source sector while leaving the included sector fixed. It checks whether included-sector data alone determine the full squared source; it is not a change permitted to the actual Weil arithmetic.
