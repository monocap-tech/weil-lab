# RC199 terminology

**Six-source canonical inverse enclosure** controls the actual canonical inverse response on P0,P2,f0,psi0,w14,v10. The seven raw trial directions also include q185. This expanded family has a separate acceptance gate from RC196's five-source family.

**Expanded variational trial** is a rational seven-by-six coefficient map selected from midpoint canonical or represented action-Gram data. Midpoints select a candidate only; directed full-domain source, residual and action-error bounds certify its actual inverse enclosure.

**Seven-term residual-tail payment** retains the common eta leading cancellation and pays seven residual remainder envelopes with a21T Gram factor. These include the new native v10 source remainder and v10 action remainder, in addition to the five previously paid terms.

**Six-source acceptance ratio** is twice the certified inverse width relative to the expanded source lower Gram. Passing requires the exact half-Gram PSD check on this same six-source family. An increase from a smaller family's width is a coverage comparison, not a regression on unchanged sources.
