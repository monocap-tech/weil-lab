# RPB-108 terminology: compact source defect localization

The compact source defect is `neutralCompactSourceDefect`: the actual
frozen corrected source action minus the pairing with the existing
zero-continued exterior residual candidate. Both are evaluated on a compact
Schwartz test. Candidate pairing integrability is proved independently.

Central restriction means values of the test on the open interval (-a,a).
The defect depends only on this restriction and vanishes on exterior tests.
For tests supported inside the open interval it equals the actual source
action. Central source cancellation therefore remains a statement about
the actual action, not about the candidate's definitional zero continuation.

Localization does not eliminate boundary-supported distributions. Smooth
central restrictions determine boundary jets. No arbitrary compact-test
realization or actual source form-domain witness is asserted here.
