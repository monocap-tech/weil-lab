# RPB108: exact kernel derivative chain

Date: 2026-10-07 UTC. Additive definitions.

- K is the actual full-native mixed-null kernel at one fixed aperture. r=dim_C K.
- F_j=K intersect global H^j of the unchanged zero extension, j>=0; F_0=K.
- For j>=1, ell_j:F_(j-1)->C is kappa_R(D^(j-1)h), using the proved actual averaged trace and global distributional derivative. The preceding derivative promotions ensure this derivative lies in K on that domain.
- A **chain generator** is nonzero h_* in F_(r-1). Its ordered physical chain is h_*,Dh_*,...,D^(r-1)h_*. It changes physical vectors by differentiation, not aperture transport.
- The **rough terminal vector** is g_*=D^(r-1)h_*. Its trace is nonzero and it is not H1.

The quotient K/(K intersect H1) is one-dimensional. This does NOT say dim K=1, that a trace is injective on K, or that a historical selected packet is a chain generator.
