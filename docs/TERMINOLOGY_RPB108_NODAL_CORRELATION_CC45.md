# Native nodal correlation (CC45)

For a real even supported vector h, write u=max(h,0), v=max(-h,0).
The cosh moment is c(h)=integral h(x)cosh(x/2)dx. If c(h)=0 and h!=0,
A=c(u)=c(v)>0 and c(|h|)=2A. The nodal comparison cost is
D(h)=H(h)-H(|h|), for the complete native pole-free form H of CC43.
It comprises the continuous gamma cross-sign integral and ALL active
prime-power cross-sign overlaps. Its dimensionless ratio is
rho(h)=D(h)/(4A^2). A null-adapted nodal estimate applies only to actual
original mixed-null vectors, not all moment-zero trials. Neither rho
nor A is an old source defect or a collective source-frame constant.
