# Moment-tail gate error budget (CC51)

The exact high carrier is Fplus from CC49, physically orthogonal to
E112 and the actual pole profile; it is kept fixed during row approximation.
W denotes its pole-free mixed-form Riesz response. A geometric error is
the change in the finite signed gate caused by replacing only the exact
compensated tail input with a polynomial approximation. It excludes
errors in the native kernel, matrix construction, high inverse/response,
moment-free low basis, and any approximation to the high carrier itself.
The signed gate is H_low minus the COMPLETE high response Gram.
