# RC193 terminology

**Extended f0 regular carrier** means the degree-1536 even Legendre polynomial representing D^-1 R f0 using a degree-512 input, a degree-192 analytic kernel, directed 600-digit interval arithmetic, exact beta/log moments, and a complete endpoint-log output-tail bound. The native f0 remains the finite source with coefficients eta_n for even 2<=n<=988 and zero otherwise.

**Omitted f0 regular input payment** means the D-norm upper bound obtained from the physical L2 energy of degrees 514 through 988, the RC174 high-mode smoothing estimate, and the lower diagonal bound D>=s_lower I. It does not redefine f0 or assert that f0 has an infinite input tail.

**Complete refined f0 canonical action error** is the absolute D-norm upper bound combining the new regular carrier error with RC176's retained endpoint and negative-r coefficient payments. The represented action remains native f0 + native w14 + the retained negative-r polynomial + the new regular polynomial. It is not an inverse-width bound or a global approximation error for M.
