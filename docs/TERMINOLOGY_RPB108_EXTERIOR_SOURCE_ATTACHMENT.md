# RPB-108 terminology: compact exterior source realization

Compact exterior source realization means the integral of the existing
`neutralExteriorResidualCandidate` against each compact Schwartz exterior
test equals `frozenWeilCompactAction`. Exterior tests vanish on (-a,a).
The action includes the actual physical source pole as well as the
right-limit fixed-cutoff multiplier core. Full-symbol growth is retained.

Pole addition is justified by actual compact-test integrability. The zero
continuation and exterior ingredients have the same pairing because the
test vanishes centrally. This is a restricted realization statement;
it does not assert the whole compact weak realization on arbitrary compact
tests or rule out a central or boundary-supported distribution defect.
