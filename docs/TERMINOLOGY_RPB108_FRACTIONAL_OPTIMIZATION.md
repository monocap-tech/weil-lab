# RPB108 fractional optimization terminology

- Distance parameter d: 1-2s, with 0<d<1 and 0<s<1/2. It is not an aperture parameter.
- Scale-dependent fractional choice: d=(K_a/log x)^(1/3), lawful when log x>=8K_a. This uses the previously derived every-s theorem, not a new domain premise.
- Gaussian approach to exponent one: upper bound x^(-1) exp(2 K_a^(1/3)(log x)^(2/3)), x=1+R/(4*pi), with a stated prefactor and Gaussian error. It does not assert exact O(R^(-1)).
- Collar approach to exponent one: squared residual bound delta exp(2 K_a^(1/3)(log(1/delta))^(2/3)), with a stated prefactor. It does not assert O(delta), traces or an exponential signed interaction estimate.
- Critical-cost budget K_a: C0+22 S_a+3847, as derived from the actual multiplier envelope and finite-prime budget. Pole moments remain in the prefactors.
