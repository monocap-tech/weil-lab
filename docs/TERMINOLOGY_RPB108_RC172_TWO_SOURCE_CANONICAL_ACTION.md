# RC172 terminology: quadratic-source regular action and canonical interface

The **quadratic physical source** is P2(x/B)=(3(x/B)^2-1)/2. It is an auxiliary even Legendre test for the polynomial regular-action construction. It does not replace a vector in the historical seven-source reference frame.

The **P2 endpoint tail xi2** has coefficients (2n+1)/[(H_n+s)(n(n+1)-6)] at every even degree n>=4 and zero elsewhere. It retains the exact infinite endpoint response. Its definition uses the actual constant s; it is not a truncated polynomial or an original Weil source.

The **two-source canonical action interface** consists of paid finite-plus-analytic trials for D^-1 L on P0 and P2, an actual full canonical Gram enclosure on their span, and a full action-error Gram upper for every real or complex mixture. The error upper pays unknown mixed errors by Cauchy–Schwarz; it does not assume orthogonality.

The **independent self-adjoint cross check** compares the P0 coefficient of Rhat P2 with one fifth of the P2 coefficient of Rhat P0. Both columns represent the same symmetric Poisson approximation, including the same far-kernel polynomial. Their rational interval intersection pays the shared mixed pairing.

L remains the actual canonical metric operator, distinct from the original Weil operator A_Q and its augmentation. This two-source action interface is not a full seven-source action certificate or a canonical inverse iteration.
