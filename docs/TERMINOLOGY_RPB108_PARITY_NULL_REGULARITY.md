# RPB108 parity null regularity terminology

First load-bearing use: PARITY_NULL_REGULARITY_20261006. Historical definitions are unchanged.

- **Physical reflection**: J h(x)=h(-x) on global zero extensions. The actual full native mixed form and canonical logarithmic norm are J-invariant.
- **Parity null sector**: K^p={h in the full actual native kernel K: J h=p h}, p=+1 (even) or -1 (odd). Its complex dimension is r_p.
- **Parity regularity flag**: K_j^p=K^p intersect H^j(R), for integer j>=0. All Sobolev membership refers to the global zero extension.
- **Parity ceiling order**: N_p=min(2 r_p,2 r_{-p}+1), for a nonzero sector. No nonzero vector of that sector can have N_p global L2 derivatives.
- **Selected parity coefficient sector**: E^p=B_c^{-1}K^p, where B_c=-G_c^{-1}R_c* is the actual null reconstruction isomorphism. These sectors need not be orthogonal in the chosen finite Euclidean coefficient norm.
- **Parity gain compression**: the compression of Gamma_s=(Lambda(c+s)-Lambda(c))/s^2 to E^p, using its Euclidean orthogonal projection. It is not an unproved parity block of Lambda on the entire coefficient carrier.
- **Dominant parity target**: finite liminf of the trace of that compression when r_p>r_{-p}. This is a sufficient conditional endpoint exclusion input, not an established arithmetic bound.
