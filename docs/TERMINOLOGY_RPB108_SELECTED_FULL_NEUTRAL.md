# RPB-108 terminology — selected and full neutral custody

The selected neutral defect uses the chosen positive synthesis P and selected negative synthesis -PC. The full shared defect subtracts the unselected negative covariance as well. Selected nullity therefore leaves that negative covariance on the same vector.

An effective positive synthesis means WD-T10's existing Spos composed with the square root of the residual background budget. It already accounts for a contractively factored negative background. The new bridge uses that existing definition; it does not redefine P or assert that WD-T38's actual P has this identification.

These are coefficient/physical defect identities. Identifying the full shared defect with the actual compact-window multiplier-plus-pole Weil form is a separate source obligation.
