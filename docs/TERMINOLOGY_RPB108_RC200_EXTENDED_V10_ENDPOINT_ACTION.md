# RC200 terminology

**Extended centered v10 endpoint carrier** means the degree-65534 finite action on a quantized degree-32766 native input, followed by25 analytic output moments and one half of the omitted actual native v10 input. Exact fixed-point sums, their quantization/rounding errors and the full geometric remainder are certified.

**Retained v10 canonical corrections** are RC197's unchanged regular carrier and finite/exact-native-tail negative-r correction. RC200 changes only the endpoint-action representation and payment. The exact native source, canonical operator and D norm are unchanged.

**Same-source action improvement** compares the complete norm-error bounds on this unchanged v10. It does not assert an inverse-width improvement; that requires rebuilding mixed rows and trial residuals for the new endpoint carrier.
