# RPB108 Green covariance obstruction terminology

First load-bearing use: GREEN_COVARIANCE_OBSTRUCTION_20261006. Historical wording is unchanged.

- **Raw Green synthesis**: T from the genuine shell l2 coefficient space to physical supported vectors, using the existing convergent Dirichlet Green series.
- **Raw gradient synthesis**: B on the same shell coefficients, using the compact derivative series; the certified global weak-derivative law is derivative(Tu)=Bu.
- **Green range metric**: the seminorm ||Tu|| in the canonical logarithmic domain, followed by quotient by ker T and completion. This differs from the Hilbert quotient of the raw l2 coefficient norm.
- **Derivative graph metric**: the norm combining physical L2 and global derivative L2 (or equivalent supported H1 norm). It is not the existing source graph norm.
- **Source graph metric**: the repository norm containing the logarithmic physical coordinate and both complete source coordinates. A derivative coordinate is not one of its defining entries.
- **Green covariance obstruction**: a bounded raw Green synthesis is compact into the infinite-dimensional logarithmic domain, so its covariance plus any finite-rank covariance cannot be coercive there.
- **Named-vector Green attachment**: a proved equality k=Tu with a genuine raw l2 coefficient u, or a derivative-graph limit with bounded/convergent derivative custody. Logarithmic range completion alone does not give this attachment.
