# RPB108 uniform exit quantifiers (CC26)

Fix the ORIGINAL complete source decomposition Q=P*P-N*N, closed positive ranges and source shells, with strict source anchor a0=21/20. Let D_s=I-T_s T_s* and K_st=T_t restricted to W_st.

| Term | Meaning |
| --- | --- |
| Uniform cap exit property | For EVERY finite B>a0 there exist h_B>0 and 0<=rho_B<1 such that for EVERY old source-positive s in [a0,B) and EVERY s<t<=min(s+h_B,B), K_st*D_s^(-1)K_st<=rho_B I. |
| Source-positive | ||T_s||<1, with a bounded positive source defect D_s. No target sign is assumed. |
| Uniform split property | Critical covariance L L*<=q_B G and low cost<=ell_B I for all the same shells, with q_B+ell_B<1 and the same cap-only step allowance. |
| Finite cap march | Partition [a0,B] into finitely many steps of length at most h_B and apply the uniform shell estimate successively. |
| Product source margin | delta_0(1-rho_B)^n, where D_a0>=delta_0 I and n is the number of completed steps. |
| Physical margin | Lower bound of Q against physical L2. It is distinct from min spectrum D_s; positive observability connects the metrics but their constants are not identified. |
| RH-strength equivalence | Under the inherited actual source/domain identification and strict anchor, the uniform cap exit property is equivalent to RH by the compact-test Weil criterion. This proves a reduction, not the property. |

A near-critical estimate without low output and non-stalling step quantifiers is not assigned this equivalence. Fixed-aperture, finite-rank, shifted-level and averaged-statistic statements retain their own scopes.
