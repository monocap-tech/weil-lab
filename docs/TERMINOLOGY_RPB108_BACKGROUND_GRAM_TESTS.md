# Actual mixed background Gram terminology

| Term | Exact meaning |
|---|---|
| Background Gram form | The mixed form inner(S+u,S+v) minus inner(SBu,SBv) on the same domain vectors, without a positivity assumption. |
| Actual Green background Gram | The preceding form pulled back by the existing bounded actual Green synthesis, equal to the existing actual background operator's mixed form. |
| Gram diagonal | The existing actual unshifted background test, given by the real part of the self-pairing. |
| Mixed Gram violation | Strict failure of the necessary inequality norm H(u,v) squared <= Q(u) Q(v). It implies a finite negative actual packet. |
| Synthesis-collision row | Two coefficient vectors with the same synthesized graph vector have equal Gram values against every third vector. No independent observations follow from repeated rows. |
| Pair certificate route | Search for a strict mixed Gram violation on actual packets; it is a sufficient obstruction, not a proof that all coordinate-pair checks establish global positivity. |
