# RPB108 pair correlation versus critical covariance (CC24)

Use beta=Re(rho)-1/2 and theta=Im(rho). The external papers instead use beta for Re(rho); their centered displacement is translated here.

| Term | Meaning |
| --- | --- |
| Unconditional scalar correlation | F(x,T)=sum_{0<theta,theta'<=T} x^(rho-rho') 4/[4-(rho-rho')^2], all multiplicity copies. |
| Normalized scalar statistic | F(T^alpha,T)/[(T/(2pi))log T], with published uniform asymptotic for 0<=alpha<=1. |
| Vertical PCC | The conjectural asymptotic count of strictly positive ordinate gaps up to lambda times the mean spacing, uniformly on fixed compact lambda intervals. |
| Finite perturbation | Add or remove finitely many reflected/sign-symmetric location copies; this is a location-measure control, not a permitted change to the actual zeta divisor. |
| Adaptive critical covariance | J M_t^(-1)J*<=q Lambda G for the ORIGINAL forced rows of the actual old critical modes, with independent low budget ell and q+ell<1. |
| Physical pulse control | A compact smooth test made from opposite translated pulses, with a polynomial Fourier filter that annihilates the opposite-ordinate off-line rows. It retains the complete background dictionary. |

A scalar pair statistic is not the signed original form. Its known positivity is an unsigned Gram fact. An averaged location asymptotic does not become an estimate uniform over adaptive critical vectors by changing its name.
