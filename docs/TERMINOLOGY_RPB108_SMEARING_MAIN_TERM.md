# Smearing main-term mismatch (RPB108 NF59)

For fixed delta>0, the **exponential smearing moment** is alpha_delta=sinh(delta/2)/(delta/2), the average of exp(-u/2) over [-delta,delta]. It is strictly greater than one.

The **pole-matched smeared form** retains the original archimedean form, uses the NF57 averaged active prime terms, and multiplies the ENTIRE original signed rank-two pole form by alpha_delta. It is an explicitly modified comparison form, not the original actual-divisor form or an actual source graph.

The two-packet parameter R below moves physical bumps to +/-R while keeping their shape and smoothing width fixed. The aperture grows with R. This is a changing family of vectors/windows, not same-vector null transport.
