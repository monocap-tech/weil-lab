# RPB108 actual native source attachment — terminology registry

- Concrete source forms: the existing full-divisor P and N mixed source forms evaluated on the same canonical Green images; all actual multiplicity copies are included.
- Source quadratic: the native signed Fourier energy plus twice the real cross-pole moment on the same physical Green synthesis. This is the numerical expression used by sourceDomainQuadratic, without constructing a retained source-domain attachment.
- Mixed source attachment: P(v,w)-N(v,w) equals twice the native mixed multiplier-plus-pole form.
- Source energy attachment: the difference of the two full, convergent source square sums equals twice the same real source quadratic.
- Factor two: full multiplicity partner sampling counts each paired orbit twice; the existing source decomposition fixes this normalization.
- Boundary: no retained WD-T38 coefficient/range identity or carrier_mem witness is supplied. Numerical source-quadratic attachment on constructed Green vectors does not instantiate NeutralSourceFormDomainAttachment for a retained carrier.
