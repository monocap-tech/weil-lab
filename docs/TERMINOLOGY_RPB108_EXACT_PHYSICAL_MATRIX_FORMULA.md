# RPB108 terminology: exact physical matrix formula

- **Symmetrized correlation:** average of the two shifted physical mixed pairings, retaining the same supported vectors.
- **Tail-free entry formula:** exact finite-interval native matrix formula with the exterior archimedean tail evaluated analytically.
- **Removable-origin evaluation:** algebraic cancellation of the integration origin's removable singularity; not a validated interval-arithmetic claim.

Definitions accompany first load-bearing use. Exact rational polynomial construction does not certify subsequent floating quadrature or eigenvalue signs. Historical wording is unchanged.
