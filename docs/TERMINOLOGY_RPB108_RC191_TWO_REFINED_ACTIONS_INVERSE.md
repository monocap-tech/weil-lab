# RC191 terminology: inverse with both refined action carriers

All historical meanings remain unchanged. The actual supported canonical M=D^-1 L, D norm, response map S=(P0,P2,f0,psi0,w14), and raw trial source map T=(P0,P2,f0,psi0,w14,q185) retain their definitions.

- **V191**: the complete represented action map retaining the RC188 psi0 action and replacing the w14 endpoint and regular components with RC190's carriers. The exact native source, identity term, and negative-r analytic tail are unchanged.
- **Native w14 tail amplitude A_w(n)**: the original fifteen-moment source polynomial at scale977132, multiplied by eta_n. This remains separate from endpoint output moments.
- **New w14 endpoint output amplitude B_w(n)**: the twenty-five retained RC190 endpoint moments at scale32766*32767. Above65534, the represented w14 action is eta_n times ((3/2-r/D_n)A_w(n)+B_w(n)). The finite regular polynomial ends at1536; its entire actual output error remains paid.
- **Merged w14 residual remainder**: the prior centered negative-r/native-moment remainder plus the new higher endpoint-output moment remainder, combined as one amplitude bound on the same w14 trial coefficient row before applying Cauchy-Schwarz. It is not discarded or asserted orthogonal to other errors.
- **Rebuilt RC191 residual**: S-V191 Y, recomputed through65534 and paid on its complete analytic tail. Its finite Gram and trial/residual cross form are not inherited from a checkpoint with the old w14 action.
- **Witness-direction triangle budget**: for a fixed response coefficient vector x, the six terms |(Yx)_i| epsilon_i are a direct valid upper-error payment for that one vector. Their proportions describe this chosen bound, not the distribution of true error or the entire inverse width.

The source-Gram normalization is held unchanged for the same-family inverse-width comparison. The half-Gram acceptance contract is separate from Stage I's original augmented Weil obligations.
