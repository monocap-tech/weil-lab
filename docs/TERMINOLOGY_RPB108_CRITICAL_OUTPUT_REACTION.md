# RPB108 finite critical-output reaction terms (NF68)

| Term | Meaning |
| --- | --- |
| Y | Independently protected finite near-unit NEGATIVE output space from NF67; retains complete source combinations. |
| G | OLD defect I-A_s restricted to Y; strictly positive when the old original gain is below one. |
| L | E K, the full incoming-shell map into Y. |
| B_low | Exact inverse-defect incoming reaction through the entire complementary output space. |
| C_W | I_W-B_low, required uniformly positive on the WHOLE incoming range W. |
| Hcrit | G-L C_W^(-1)L*, the exact finite remaining original gain gate. |
| Relative reaction Rcrit | G^(-1/2)L C_W^(-1)L*G^(-1/2); original continuation requires norm below one. |
| Z | Old physical representer P_s^(-1)T_s*A_Y^(-1), satisfying N Z n=n. |
| Jtrial | L U+U*L*-U*C_W U, a LOWER enclosure of the reaction, not an upper one. |
| Eres | L*-C_W U, whose WHOLE mixed residual Gram pays the missing inverse reaction. |

Proof and scope: [NF68](../notes/REFLECTED_PACKET_BRIDGE_108_CRITICAL_OUTPUT_REACTION_20261008.md). No actual source-coordinate matrix or zeta bound is evaluated.
