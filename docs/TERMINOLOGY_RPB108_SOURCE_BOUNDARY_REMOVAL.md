# RPB-108 terminology: regular source defect boundary removal

A regular actual defect representative is a locally integrable function q
whose pairing with every compact Schwartz test equals the already defined
actual compact source defect. This is an explicit witness obligation; it is
not implied by exterior equality or by distributional temperateness.

Actual central source cancellation means the frozen corrected source action
is zero on each compact Schwartz test with topological support inside (-a,a).
It is distinct from the candidate's definitional central vanishing and from
the abstract interface's endpoint null equation.

Regular boundary removal means exterior attachment plus actual central
cancellation force a regular defect representative to vanish almost
everywhere on the whole line. Compact-test detection supplies the open-set
statements, and the two endpoints have zero volume. Thus there is no remaining
boundary contribution within this regular class. The theorem does not
construct regularity or central cancellation and makes no assertion about
singular defects without those witnesses.
