# Actual Green multiplicity-copy observability terminology

| Term | Exact meaning |
|---|---|
| Unit Green synthesis | A single actual divisor coefficient synthesizes its endpoint-corrected Green column, scaled by that coefficient. |
| Same-ordinate copies | Actual divisor coordinates with equal complex Bombieri ordinate; multiplicity indices can differ. |
| Synthesis collision | Difference of two unit coefficient vectors with identical actual graph packet images. It is nonzero when their indices differ. |
| Graph-analysis coordinate | Inner product of the actual graph packet with the input vector in the full graph Hilbert space. |
| Copy observation redundancy | Same-ordinate copies have equal graph-analysis coordinates; their multiplicity still remains in energy sums. |
| Kernel distinction | The synthesis kernel is in coefficient space; the analysis kernel is in source graph space. A collision in the former does not prove a nonzero vector in the latter. |
