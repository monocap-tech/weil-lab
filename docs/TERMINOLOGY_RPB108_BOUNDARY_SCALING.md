# RPB108 boundary scaling terminology

- Boundary scaling: x=a+epsilon t and y=a-epsilon z with t,z in [1,2], for the actual exterior kernel.
- Half-Carleman decomposition: H_k=(1/2)C_L+H_r on physical L2(0,L), with H_r Hilbert-Schmidt. It is not an assertion that the full prime operator is compact.
- Physical collar noncompactness: noncompactness of the actual exterior residual map DENSELY defined on carrier vectors and extended to physical L2([-a,a]), with target L2(a,a+delta), delta fixed and positive. This does not assert noncompactness with the logarithmic carrier norm.
- Norm-only shrinking-collar obstruction: failure of a uniform positive-power squared residual bound for arbitrary unit-logarithmic-norm vectors. It is not a weak-null counterexample or a signed Gaussian lower bound.
- Boundary concentration vectors: explicit step vectors h_epsilon, lawful in D_a but not asserted to solve any null equation.

Definitions precede their use in the same promotion. Historical notes remain unchanged. F4, FULL TRANSPORT CLOSED, global endpoint exclusion and selected-witness attachment remain open.
