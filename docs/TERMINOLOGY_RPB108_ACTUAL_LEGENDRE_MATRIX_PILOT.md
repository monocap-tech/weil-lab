# RPB108 terminology: actual Legendre matrix pilot

- **Legendre trial vector:** physical L2-normalized polynomial on the supported interval, with proved logarithmic form-domain membership.
- **Truncated native matrix:** actual multiplier pairing cut off in frequency, with the native pole pairing included.
- **Pilot Rayleigh value:** exploratory numerical eigenvalue in the physical orthonormal trial basis; not an eigenvalue of the full logarithmic Riesz operator.

Definitions accompany first load-bearing use. Repeated quadrature agreement is not a rigorous sign certificate. Historical wording remains unchanged.
