# DNE48 terminology: trial source response

Registered before DNE48 load-bearing computation. Parent DNE47,
`da5b09e3b72b8e05e3daab5e37e6b3398a5558f8`.

* **Trial source extension**: the original even source packet extended from
  44 to 47 columns by DNE47's three exact high trial polynomials. Its 138
  new upper-triangle correlations are integrated directly; old entries
  remain unchanged.
* **Trial native pairings**: M=Z*L_original Y and A=Y*L_original Y,
  evaluated from the new complete source coordinates against the exact
  physical polynomial columns, with original analytic source errors paid.
* **Paid response matrix**: for frozen rational J, the matrix
  kN-G+(B-kM)J+J*(B-kM)*-J*(D-kA)J at k=647/1000.
  Positivity pays every mixed packet entry and implies the original finite
  Schur sign. Failure is inconclusive about the original sign.

No geometry, numerical proposal, or unvalidated source archive upgrades
the standing 87 retained directions. Whole-aperture positivity, actual
high inverse evaluation, RH, and Lean remain open unless separately proved.
