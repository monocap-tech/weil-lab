# RPB108 leading rough translation flux

Registered 2026-10-06 (America/Los_Angeles), before load-bearing use.

- D_w(t;h)=integral log(e+|xi|)(1-cos(2 pi xi t))|hhat(xi)|^2.
- D_mass is the same defect with multiplier 1.
- A bounded multiplier correction is a real measurable b with finite essential supremum. At fixed actual aperture m_a-w is such a correction.
- Phi_mu(h;t)=-D_(m_a-mu)(t;h)+(cosh(t/2)-1)P0(h) is a comparison spectral functional. It equals genuine exterior flux only when h satisfies the actual interior eigen-equation with eigenvalue mu.
- Leading rough equivalence means Phi_mu(h;t)/(-D_w(t;h))->1 for a fixed non-H1 physical h with finite logarithmic energy.
- Uniformity in bounded mu refers to the comparison functional on that same fixed h. It does not assert uniformity in moving eigenvectors, supports, or kernels.

Physical h is unchanged in the comparison. Different choices of mu do not make the same h an eigenvector at several eigenvalues.
