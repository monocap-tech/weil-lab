# RPB108 fractional null regularity terminology

- Y_s: whole-line Fourier space with squared weight (1+|xi|)^(2s), equivalent to H^s. This promotion only establishes 0<s<1/2 for actual full mixed weak-null vectors.
- Capped fractional weight rho_M: min((1+|xi|)^s,M), M>=1. Its boundedness lets the proof estimate a new domain without assuming membership in that domain.
- High-frequency absorption: use of the actual logarithmic multiplier lower envelope to absorb a bounded capped-norm term from the full mixed equation. It is distinct from inferring fractional regularity from all logarithmic moments.
- Null-space shrinking-collar power bound: squared actual residual L2 mass O_(a,s)(delta^(2s))||h||_2^2 on either exterior collar, conditional on full mixed nullity. It is not a bound for arbitrary carrier vectors, nor an exponential signed Gaussian estimate.
- Gaussian power rate below exponent one: M_R=O_(a,alpha)(R^(-alpha))||h||_2^2 for each 0<alpha<1. No alpha=1, H^(1/2), trace, H1 or exponential rate is supplied.
