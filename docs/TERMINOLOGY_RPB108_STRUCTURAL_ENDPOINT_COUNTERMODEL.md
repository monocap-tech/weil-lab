# RPB108 terminology: structural endpoint countermodel

- **Structural comparison family:** explicitly defined non-zeta forms testing an implication from a specified list of structural properties.
- **Structural endpoint countermodel:** a comparison family with a finite positive endpoint, disproving endpoint exclusion from those properties alone.

This terminology does not assert a counterexample to RH or replication of every actual-zeta premise. Definitions accompany first load-bearing use; historical wording remains unchanged.
