# RPB108 compact C² inverse attachment terminology

Defined with first load-bearing use in the companion proof note.

- **Inverse representative** J_a(v,w) is the already defined inverse integral of S_a(v,w), with C² regularity already derived from its first two absolute Fourier moments.
- **Original compact correlation** K_a(G_a(v),G_a(w)) is the previously certified conjugate-reflected compact-window kernel.
- **Inverse attachment** means the proved almost-everywhere identity J_a(v,w)=K_a(G_a(v),G_a(w)). It follows from Fourier integral duality, the certified spectrum identity, Schwartz inversion and compact smooth test uniqueness.
- **Pointwise exterior support** means J_a(v,w)(t)=0 for every t outside [-2a,2a]. It is derived from almost-everywhere attachment and continuity on the open exterior, using positivity of volume on nonempty open sets.
- **Compact C² test carrier** is the same inverse representative J with both ContDiff ℝ 2 and HasCompactSupport proved. No test-function premise is supplied.
- **Sample transport** uses the inverse attachment to identify every all-complex raw-transform sample with the original compact correlation's sample; this includes actual nonreal divisor ordinates and the two pole values.
- **Same canonical Green image** is the existing neutralCanonicalToLogHilbert image of G_a(v), which reconstructs the same physical vector. This does not identify the retained WD-T38 mode.
