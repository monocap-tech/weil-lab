# RPB-108 raw actual-divisor Green sampling terminology

| Term | Definition | Certified scope |
| --- | --- | --- |
| Raw window evaluation | Integral of f(x)exp(i*z*x) over [-a,a] | Physical L² continuous pairing |
| Raw column derivative identity | i*z*E(G)=-E(D) | Individual Dirichlet columns and full actual synthesis |
| Raw actual-divisor sample | E(a,gamma(q),G(a,v)) | Square summable over all actual multiplicity copies |
| Actual raw sampling input | Green synthesis from actual lp² coefficients | Supported H¹ subclass of canonical log domain |

“Raw” refers to the exponential evaluation kernel. The sampled input remains
the constructed Green synthesis. This is not a claim of raw sampling for an
arbitrary vector in the entire logarithmic form domain, or of identification
with the independently supplied WD-T38 mode.
