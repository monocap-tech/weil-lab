# Canonical carrier architecture terminology

| Term | Exact meaning |
|---|---|
| Raw divisor carrier | The existing l2 space indexed by every actual divisor multiplicity copy; retained for coefficient and energy accounting. |
| Algebraic observational quotient | Domain modulo the kernel of the named map, canonically linearly equivalent to that map's range. No norm equivalence is implied. |
| Quotient observation norm | Norm of the quotient class's range image. For synthesis it is the graph norm of Gv; for positive analysis it is the norm of S+f. |
| Observation completion | Closure of the range of the named map in its target Hilbert space, with the induced target norm and dense same-vector observation map. |
| Green observation carrier | Completion for the graph-image norm of actual Green synthesis; exactly the certified Green graph closed submodule. |
| Positive-energy carrier | Completion of the source graph modulo the positive-analysis kernel in the positive observation norm; realized as the closure of the positive-analysis range. |
| Relevant positive carrier | The same construction with positive analysis restricted to the certified Green graph domain. No full-domain density is assumed. |
| Algebraic background descent | Kernel inclusion ker S+ <= ker SB; equivalent to a linear map out of the positive quotient, without a boundedness claim. |
| Unit background domination | Norm SBf <= norm S+f on the stated domain; equivalent to unshifted covariance order and a unique induced contraction on the positive completion. |
| Completion recovery | A bounded same-vector inverse from the positive completion back to the graph domain; equivalent to a graph-norm lower bound by positive energy. It is not needed merely to use that completion as WD-T10's positive coefficient carrier. |
| WD-T10 canonical factor | Negative adjoint of the induced contraction; preserves the actual background adjoint and supplies the signed synthesis factor. |
