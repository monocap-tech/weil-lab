# RPB108 signed budget and circularity (CC23)

Fix the complete original normalized source form Q=P*P-N*N on a finite cap. For s<t, V_s=P(D_s), W=V_t intersect V_s perpendicular, T_s(P h)=N h, and K=T_t restricted to W.

| Term | Definition |
| --- | --- |
| Old input defect H | I-T_s*T_s on V_s. |
| Old output defect D | I-T_s T_s* on the complete negative ambient. |
| Whole relative budget B_st | K*D^(-1)K on the complete incoming shell W. |
| Signed completion | The exact source Gram completion Q_t(p,w)=<p-H^(-1)T_s*K w,H(p-H^(-1)T_s*K w)>+<w,(I-B_st)w>. |
| Unit budget | B_st<=I; equivalent to original Q_t>=0 when the old gain is strictly below one. |
| Strict budget | ||B_st||<1; equivalent to a positive-source coercive target gain strictly below one under the same old assumption. |
| Circular signed Cauchy-Schwarz | Applying |Q_t(h,f)|^2<=Q_t(h,h)Q_t(f,f) on the enlarged domain to establish its positivity; validity of this inequality on all pairs already requires Q_t>=0. |
| Diagonal control | Bounds on separate source energies or row masses, without their cross-correlation. These are insufficient to determine the shell Schur sign. |

The critical restriction L L*<=q G with an independent low budget ell and q+ell<1 remains a sufficient partitioned condition. It is not equated with the exact unpartitioned criterion ||B_st||<1.
