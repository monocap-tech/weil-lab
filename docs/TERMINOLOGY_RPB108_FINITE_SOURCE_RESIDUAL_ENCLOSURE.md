# RPB108 terminology: finite-source residual enclosure

Introduced with REFLECTED_PACKET_BRIDGE_108_FINITE_SOURCE_RESIDUAL_ENCLOSURE_20261006.md.

- **Trial map Y:** a specified map from finite selected coefficients to actual canonical physical vectors, approximating G^(-1)R^*.
- **Residual E:** R^*-GY as a logarithmic Hilbert functional/Riesz map.
- **Hermitian trial response V:** RY+Y^*R^*-Y^*GY. A generic RY is not necessarily Hermitian.
- **Full residual Gram K:** E^*E, retaining all column correlations; an attached physical residual Gram F^*F can replace it with the stated inclusion or physical coercivity bound.
- **Response enclosure:** V<=L<=V+beta^(-1)K for L=RG^(-1)R^*, with certified coercivity and exact trial/source custody.
- **Explicit negative trial witness:** Yu when u^*(I-V)u<0; its full native energy obeys the exact identity in the note.

The rational comparison controls validate algebraic conventions only. They do not supply actual selected ordinates, a coercivity constant, a physical residual enclosure, a computed actual matrix, or endpoint exclusion.
