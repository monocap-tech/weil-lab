# CC81 — residual response after the four-column minorant

Definitions are additive. The NF42 operator A1 is the four-high-column minorant attached to H=(Z,Y), under the explicit remaining-high floor hypothesis. The residual defect D1=A-A1 is positive semidefinite in form order. The improved joined lower matrix K1=Q-R*A1^-1R and actual residual response T1=R*(A1^-1-A^-1)R retain NF42's meanings.

An additional source column y is a frozen original high form-domain vector with a physical operator image, independent of the four current high columns. Set f1=D1 y, d1=<y,D1 y>, p1=f1*A1^-1R and b1=d1+<f1,A1^-1f1>. For d1>0, its rank-one response credit is p1*p1/b1, with p1 a one-by-three signed row. It is a lower matrix bound for T1. The new source column is not an assumed actual eigenvector.

The residual witness efficiency is |p1 h|^2/b1 for NF38's frozen, unnormalized witness h. It is unchanged by nonzero rescaling of y. Passing the necessary witness deficit is a rejection screen; sufficiency requires the entire paid matrix K1+p1*p1/b1 to be positive in each parity, including all mixed entries.
