# RPB108 actual logarithmic-operator attachment

On I_a=(-a,a), L_a is the exterior Dirichlet realization of the angular-frequency multiplier 2 log|eta|. It is not the spectral logarithm of the local Dirichlet Laplacian.

The actual correction B_a is c0 I-J_a-T_a+P_a. Here J_a has kernel j(s)=exp(-s/2)/(1-exp(-2s))-1/(2s), continuously extended by j(0)=1/4; T_a retains all frozen actual prime shifts, including thresholds; P_a has kernel 2cosh((x-y)/2). B_a is bounded self-adjoint on physical L2(I_a).

The actual supported native operator A_a equals L_a/2+B_a with the SAME physical vector, form domain and operator domain. This comparison changes the operator, not the vector or source-analysis coordinates.

The null-specific compatibility is L_a h=-2B_a h. For an actual eigenmode it is L_a h=2(mu h-B_a h); the mass residual is retained. Neither equation is enlarged or full-line cancellation.
