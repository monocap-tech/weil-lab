# RPB-108 real-axis digamma bounds supplement

**Real-axis digamma bracket** means log(x-1)≤Re ψ(x)≤log x for x>1,
derived from actual Gamma log-convexity, differentiation and recurrence.
The upper bound also holds for every x>0.

**Shifted zero-frequency bracket** applies that estimate to x=N+1/4,
including the actual source subtraction log π. It is an independent
estimate of the scalar multiplier value. It does not control the centered
frequency-dependent remainder or prove shifted-tail vanishing on tests.
