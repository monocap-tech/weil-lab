# RPB108 terminology: explicit certificate cost

- **Explicit archimedean envelope:** a stated uniform constant for the actual digamma/logarithmic difference.
- **Sufficient certificate size:** cutoff and finite degree proving an error bound; not an intrinsic lower bound for other methods.
- **Certificate cost audit:** evaluation of that chosen construction's size, without claiming a practical implemented solver.

Definitions accompany first load-bearing use. Illustrative arithmetic does not certify a matrix sign. Historical wording is unchanged.
