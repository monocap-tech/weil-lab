# RC201 terminology

**RC200-attached six-source inverse** is an actual canonical inverse-response enclosure on the unchanged P0,P2,f0,psi0,w14,v10 family. It replaces only v10's endpoint-action representation and error with RC200, retaining its source, negative-r correction and regular action.

**Refined mixed reconstruction** includes RC200's endpoint polynomial through65534, centered native input beginning32768 and analytic endpoint output beyond65534 in every relevant pairing and residual. The smaller error is not substituted into unchanged RC199 nominal matrices.

**Same-family inverse comparison** uses the same source Gram, operator, aperture and D norm as RC199. Inherited RC199 endpoints remain valid candidate bounds. The selected inverse width and acceptance margin are separate from the action-error improvement.
