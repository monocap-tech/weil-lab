# RPB108 boundary continuation terminology

Registered with first repository custody. Base: d17a74065324575654cd53ea394957dfa4961ebb.

- Two-factor signed Gaussian bound: fractional weighted Cauchy-Schwarz applied to h and the frozen multiplier core L_h; it bounds the genuine whole-line Gaussian action, and a fixed collar after adding the separated far-field error. It is not an exponential cancellation theorem.
- Critical exterior Hardy integral: J_a(h)=integral_(-a)^a |h(x)|^2[1/(a-x)+1/(a+x)]dx. Finiteness is necessary for zero-extension H^(1/2); the interior Gagliardo contribution is an additional obligation.
- Translation boundary flux: F_h(t)=Re integral_a^(a+t) r_h(x) conjugate(h(x-t))dx, for 0<t<min(1,2a). The residual and source are the same actual full mixed weak-null vector's data. Its sign is fixed as written.
- Logarithmic Fourier increment: D_w(t)=integral log(e+|xi|)(1-cos(2*pi*xi*t))|Fourier(h)(xi)|^2 dxi. The frozen multiplier increment D_m uses m_a instead of w.
- Critical integrated translation flux condition: integral_0^t0 |F_h(t)|dt/t^2<infinity. Under the pinned actual mixed-null hypotheses it is equivalent to finite integral |xi|w(xi)|Fourier(h)(xi)|^2 dxi. Neither condition is established for actual null vectors here.
- Comparison logarithmic boundary profile: 1/sqrt(log(1/t)) at small positive t. This is drawn from the logarithmic Laplacian comparison literature; no actual-zeta boundary asymptotic is inferred.
