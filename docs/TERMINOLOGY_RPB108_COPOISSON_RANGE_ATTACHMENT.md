# RPB108 co-Poisson range attachment

For a physical vector h supported in [-a,a], write H_h(s)=integral h(x)exp((s-1/2)x)dx and f_h(t)=t^(-1/2)h(log t). Its right Mellin transform is H_h(1-s).

The co-Poisson attachment T_a h has right Mellin transform zeta(s)H_h(1-s). On the established weak-critical class it belongs to L_lambda, lambda=exp(-a), where the function and its cosine transform are constant on (0,lambda). This is a new nonlocal physical vector, not same-vector native null transport.

Its completed Mellin zero jets vanish because of multiplication by zeta. That property does not assert H_h(rho)=0, individual native p/n vanishing, or the full mixed-null equation. The map is injective but does not attach a nonzero h to L_1. L_1 completeness therefore requires an additional actual-null-specific compatibility theorem.

This is an analytic candidate-framework obstruction. The global remaining gate is still nonpositive actual signed sharp/log liminf; F4 is unproved.
