# RPB-108 Laplace Fourier supplement

Registered before first load-bearing use, 2026-10-01.

- **Laplace kernel**: the integrable physical function exp(-b|x|), b>0.
- **Finite Gauss resolvent transfer**: the exact normalized Fourier transform
  of a Laplace kernel at b=2n+1/2 is the real reciprocal coefficient in the
  finite digamma recurrence. This is a transform identity, not yet a whole
  Gauss operator limit or source realization.

The shifted digamma tail and central/boundary attachment remain separate.
