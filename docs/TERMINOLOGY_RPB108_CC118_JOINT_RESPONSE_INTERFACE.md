# CC118 joint even response interface

CC117's even comparison A and DNE50's even comparison B bound the same
original retained/high Schur form from below. An exact vector z with
z^T A z<0 and z^T B z<0 rejects every convex mixture (1-t)A+tB for 0<=t<=1.
This concerns those two paid fixed comparisons, not original Weil negativity
or every choice of high trial coefficients.

The joint physical high frame is J=(Y_CC11,Y_DNE3), in that order. Its exact
physical Gram establishes 14 independent high directions, not 14 new
retained directions. Its diagonal source/native response blocks are already
paid. Define the 11-by-3 mixed original native matrix T=<Y_CC,L Y_DNE> and
the mixed projected-source matrix U=<P_F L Y_CC,P_F L Y_DNE>. The missing
denominator block is X=U/k-T, k=647/1000. There are 33 mixed source entries.
The native block is recovered from <L Y_CC,Y_DNE> using the complete CC105
action coordinates and whole-source L2 errors; its opposite orientation uses
the inherited symmetry/domain theorem for the original operator.

The complete denominator would be [[N_CC,X],[X^T,N_DNE]], where
N_DNE=W_DNE/k and W_DNE is DNE50's residual denominator. The signed response
rows would be [W_CC,E_DNE]. DNE50's E_DNE and W_DNE use the same residual
identity as CC117, with the stated factor of k. Unknown X cannot be set to
zero and the two separate response credits cannot be added.

Once X is paid, a frozen rational 14-by-56 H can be tested using the exact
fixed-trial residual inequality. This interface needs no new Z56 source
entries or retained/native pairings. The 33 mixed source entries are a
matrix-interface count, not a runtime or universal minimal-cost theorem.
Original analytic source/domain/high-floor theorems remain inherited.

Y=(e1,e1+e2), and retained native q=3/8. These high vectors are independent.
