# RPB108 terminology: canonical positivity aperture

- **Canonical full-source positivity aperture:** A=sup{a>0: Q_a>=0 on all of D_a}, an extended positive real. The positivity set is proved to be (0,A] when A is finite and all finite windows otherwise.
- **Endpoint collar saturation:** positive physical L2 mass in every collar at both support endpoints. This is essential support, not an endpoint-trace or regularity assertion.
- **Attained unit-gain space:** ker(I-T_A* T_A) in the closed positive-analysis range, canonically equal to P_A ker Q_A at a finite positive endpoint.
