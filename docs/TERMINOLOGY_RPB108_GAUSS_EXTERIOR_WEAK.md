# RPB-108 exterior Gauss weak convergence supplement

**Support-separated test** here means a Schwartz test vanishing on (-a,a),
with 0≤c<a and actual carrier support in [-c,c].

**Exterior finite Gauss weak limit** is convergence of the genuine physical
pairing to minus the signed gap-function pairing, with error bounded by
the exterior geometric error times the test's actual L1 norm.

**Exterior source-attachment defect** is actual archimedean multiplier
action minus signed gap-function pairing. The actual shifted digamma tail
pairing converges to this defect. Tail vanishing is exactly equivalent to
source attachment on the test; the equivalence does not prove either side.
