# Parity pole correlation (CC35)

Use the complete native decomposition and notation of CC33. Split its
canonical remainder C_t=C_0,t+C_pole,t, where C_0,t retains the actual
archimedean remainder and every active prime-power shift pair. Put
Pi=Pi^D_st, q_0=(I-Pi)C_0,t h and q=(I-Pi)C_t h.

For an even lift set g(x)=cosh(x/2), sigma=+1; for an odd lift set
g(x)=sinh(x/2), sigma=-1. Define a=2 int g(x)h(x) dx,
ell=i_t* g and v=(I-Pi)ell. Then q=q_0+sigma a v.
All profiles are restricted to [-t,t]; h is old supported.

The complete dual metric is [u,w]_* = <M_t^-1/2 u,M_t^-1/2 w>_D.
When v is nonzero, write the orthogonal decomposition in this metric
q_0=z v+q_perp. The pole correlation coefficient z is determined by
this projection; it is generally not the canonical projection coefficient.
The transverse energy is ||q_perp||_*^2 and the pole mismatch energy
is ||v||_*^2 |z+sigma a|^2. Both are nonnegative.
