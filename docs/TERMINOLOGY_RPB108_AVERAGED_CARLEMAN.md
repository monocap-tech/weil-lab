# RPB108 averaged Carleman terminology

Base: 4078bf1ad97435e754b22d067b5c68a8ac5826be. Registered with first use.

- Inverse boundary moment: M(f)=integral_0^L f(v)dv/v, only when defined. Absolute integrability is required for the unregularized identity.
- Edge-truncated profile: f_epsilon=1_[epsilon,L]f. This changes the comparison profile; it is not claimed to preserve actual mixed nullity.
- Averaged Carleman pairing: integral_0^infinity S_f(t)dt/t^2, with S_f(t)=Re integral_0^t C_L f(u) conjugate(f(t-u))du and C_L f(u)=integral_0^L f(v)dv/(u+v).
- Bounded nonnegative edge sector: the extra conditions f real, nonnegative, bounded. Reflection parity does not supply nonnegativity or boundedness.
- Quadratic-versus-linear boundary obstruction: divergence of the squared inverse moment dominates the linear bounded-background contribution in the regularized flux inequality. This is not an actual endpoint existence or exclusion claim.
