# RC208 terminology

Coupled action-error payment combines the same action error in the variational term and actual residual before applying Young's inequality. It retains their algebraic dependence rather than assuming independent errors or bounding each contribution separately.

The lower combined error vector is u+r0; the upper is u+2r0/a, where r0=s-v is the represented residual. Their full Grams use the inherited physical source/residual data and paid cross tails. The directional error Gram is exactly RC206's Gram; no new physical error reduction is claimed.

The new relative inverse width is 0.597416, above the 0.5 half-Gram threshold. It is below RC207's 0.655936 barrier because RC207 covered a different, separately paid enclosure family. This is a lawful method change, not a contradiction of the barrier.

RC209 targets the coupled error envelope and full residual/cross-tail data. Native coverage and original augmentation are still required. Stage I, RH, F4 and Lean closure remain open.
