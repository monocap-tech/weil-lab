# RPB108 terminology: actual exterior moment rigidity

- **Exterior moment generating function:** the holomorphic function integral exp(5y/2)h(y)/(1-z exp(2y))dy, whose coefficients are Laplace moments of the same physical vector.
- **Weighted tail observation:** exp(-sigma x) times the actual native residual on x>L, with L>3a and sigma>1/2.
- **Exterior moment rigidity:** zero actual residual on an open far interval forces the original physical vector to vanish.

Rigidity is an injectivity statement; it does not mean a stable inverse on the full carrier. Definitions accompany first load-bearing use, without changing historical terminology.
