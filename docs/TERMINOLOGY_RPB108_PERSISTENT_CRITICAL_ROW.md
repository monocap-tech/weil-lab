# RPB108 persistent critical row terminology

CC32, 2026-10-08. Original complete source metric and exact shell.

- **Expected contact defect:** d_s=<y,(I-A_s)y> for the actual unit
  output y of a hypothetical contact A_a y=y. It tends to zero from
  below-contact apertures; it is not a physical certificate margin.
- **Contact flux:** gamma=<y,(A_t-A_a)y>>0 at a FIXED strict enlargement
  t>a, conditional on an actual contact existing. This is CC29's flux.
- **Diagnostic defect filter:** F_s=1_[1-epsilon_s,1)(A_s), with
  epsilon_s=C d_s. It is used to locate a row inside the cap-only fixed
  CC31 critical band, not to replace that band's continuation target.
- **Persistent row leakage:** a_i=<y_i,(A_t-A_s)y_i>=||K_st* y_i||^2
  for a unit actual critical eigenvector. By CC20 it equals
  ||M_t^-1/2 J_i*||^2/lambda_i.
- **Selected-row statement:** for every sufficiently near-contact s,
  some eigenvector has delta_i<=C d_s and a_i>=gamma/(2d_B).
  Its index, phase and eigenspace choice may change with s.

All contact statements are conditional. No actual contact, numerical
gamma, continuous eigenvector branch, or arithmetic upper bound is claimed.
