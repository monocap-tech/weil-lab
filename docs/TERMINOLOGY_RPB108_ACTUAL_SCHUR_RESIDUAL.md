# RPB108 actual Schur residual terminology

- **Physical residual certificate:** rigorous L2 enclosure of the actual interior source after removing physical Legendre degrees 0..63.
- **Approximate lift:** a specified linear map from the finite low space to the proved coercive complement, used to approximate the exact complement solution.
- **Residual Gram R:** the same-vector matrix of physical residual inner products; the bound S_Z-5R<=S<=S_Z retains all uncomputed complement directions.

Definitions are additive; historical wording is unchanged.
