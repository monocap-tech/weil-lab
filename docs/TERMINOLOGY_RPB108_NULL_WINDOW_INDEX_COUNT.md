# RPB108 terminology: null-window index count

- **Null window:** positive aperture with a nonzero actual full native weak-null space.
- **Old invertible complement:** logarithmic orthogonal complement of the old kernel, with a bounded invertible form operator that may be indefinite.
- **Null-window index count:** negative-index difference between non-null apertures equals the sum of intervening nullities.
- **Local index budget:** finite negative index at a single fixed larger aperture; no globally uniform finite-index bound is implied.

Definitions accompany first load-bearing use. Historical wording remains unchanged.
