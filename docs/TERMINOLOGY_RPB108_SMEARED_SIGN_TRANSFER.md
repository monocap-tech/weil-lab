# Smeared sign transfer (RPB108 NF58)

Keep Q_a the ORIGINAL actual form and Q_(a,delta) its NF57 prime-smearing approximation. A **bounded-level eigenvector** is a physical eigenvector of the original supported operator with eigenvalue mu satisfying |mu|<=M, where M is a fixed finite constant. It is not presumed null.

Let X_k have norm ||h||_(X_k)²=integral log(e+|xi|)^(2k)|hhat(xi)|²dxi. The constants L_(a,M,k) below bound this norm by L_(a,M,k)||h||_2 on bounded-level eigenvectors.

The **eigenvector smearing budget** is

    epsilon_(a,M,k)(delta)
      =S_a[(32/3)delta+2 L_(a,M,k)²(2/log(1/delta))^(2k)].

It bounds the original-minus-smeared quadratic value relative to physical mass on those original eigenvectors. It is not a bound on every form-domain vector, on an arbitrary numerical trial subspace, or on freely prescribed source coordinates.
