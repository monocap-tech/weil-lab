# RPB108 archimedean tail-repair terms (NF65)

| Term | Exact meaning |
| --- | --- |
| Original tail R_N | Sum of f_z(N+1/4+j) over all j>=0, z=pi^2 xi^2; the omitted positive original archimedean multiplier. |
| Integral main term I | (1/2)log(1+z/q^2), q=N+1/4; retains high-frequency logarithmic growth. |
| Laplace derivative d_r | Integral t^r exp(-qt)(1-cos(sqrt(z)t)) dt; nonnegative and <=2r!/q^(r+1). An explicit rational multiplier, not a derivative of h. |
| Finite repair S_m | I+(1/2)f_z(q)+sum_{k=1}^m B_(2k)d_(2k-1)/(2k)!. Even m is lower; odd m is upper. |
| Global finite remainder | Exact rational denominator identity, valid for all positive t, followed by a nonnegative Laplace integral. Not an infinite Taylor-series extrapolation. |
| Epsilon_(N,m) | |B_(2m+2)|/[(m+1)q^(2m+2)] for even m; uniform physical-mass error. At N=32,m=16 it is <10^-40. |
| Q_minus / Q_plus | Original complete primes and exact signed pole with arch symbol m_32+S_16 / m_32+S_17. Same logarithmic form domain as the original. |
| Relative-mass control | 0<=Q_original-Q_minus<=epsilon mass; in derivative space, 0<=C_original-C_minus<=epsilon M_a. |
| Anchor transfer | Existing original whole positivity at a=1 implies whole positivity of Q_minus there. It is not a new original aperture certificate. |
| Whole sign still required | A uniform approximation allowance alone does not determine the original sign at a=21/20 or on every finite aperture. |
| Eigenlevel shift | Subtract identical mu mass from original and repaired forms; approximation errors remain unchanged and original zero level is not inferred. |

Proof and scope: [NF65 note](../notes/REFLECTED_PACKET_BRIDGE_108_ARCHIMEDEAN_TAIL_REPAIR_20261008.md). The original actual-divisor source gain, the bare-cutoff compact gain, and the repaired comparisons remain distinct.
