# RPB108 actual selected/background terminology — 2026-10-04

Definitions precede load-bearing use in ActualZetaSelectedBackground.lean.

| Term | Exact meaning |
| --- | --- |
| Selection | A finite set of actual divisor multiplicity coordinates. It need not contain both partners; no orbit quotient or repeated-channel convention is silently applied. |
| Selected projection | Continuous ℓ² projection retaining precisely the finite selected coordinates. |
| Background projection | Identity minus the selected projection, retaining all unselected coordinates. |
| Source normalization | Multiplication of full-divisor source coefficients by 1/sqrt(2). The existing pair sources already have their own 1/sqrt(2) factor; this second factor removes full-divisor partner double counting. |
| Normalized selected negative analysis | Selected projection of normalized full negative analysis on the concrete source graph. |
| Normalized background negative analysis | Complementary projection of the same normalized full negative analysis. |
| Source quadratic | Normalized positive squared norm minus normalized full negative squared norm on the graph. |
| Effective-background quadratic | Normalized positive squared norm minus unselected normalized negative squared norm; it equals the source quadratic plus finite selected negative energy. |
| Green arithmetic attachment | On each unchanged Green lift, the source quadratic equals the zero-form real part and hence the native multiplier-plus-cross-pole quadratic. The effective-background quadratic adds half the raw selected source energy. |

Neither the word effective nor this signed expression asserts positivity, a square-root factorization, or identification with WD-T10/WD-T38's effective-positive synthesis. The graph norm remains distinct from the original logarithmic carrier norm. Orbit-selection custody, form extension and retained-mode membership remain proof obligations.
