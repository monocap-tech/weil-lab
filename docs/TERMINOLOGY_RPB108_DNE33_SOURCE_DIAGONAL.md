# RPB108 — DNE33 terminology: complete projected-source diagonal

Definitions are additive. DNE31's frozen frame and DNE32's native certificates remain unchanged.

**Native-normalized remainder X:** the exact polynomial packet X=hatY U fixed in DNE32. Its original native matrix C=Q(X,X) is enclosed by the DNE32 congruence certificate. The normalization concerns native energy, not physical L2 mass.

**High source probe e_n:** a physical L2-normalized Legendre mode with n>=112 and the same reflection parity as X. It belongs to F112 and is orthogonal to all retained E112 modes.

**Original high source coordinate:** b_n=<L_original X_j,e_n>=<P_F112 L_original X_j,e_n>. It includes the endpoint logarithms, regular archimedean source, signed pole, and all six prime-power translations in both orientations. Its interval includes the uniform original-source approximation error times the exact packet's outward physical norm.

**Finite Bessel lower bound:** the sum of squared distances of finitely many coordinate intervals from zero. Physical orthonormality implies that this number is at most ||P_F112 L_original X_j||^2. Unmeasured source coordinates cannot reduce the bound.

**Complete projected-source diagonal:** the squared physical norm of P_F112 L_original X_j, including every high component. It is computed by analytic whole-source integration followed by subtraction of all 56 same-parity retained source-coordinate squares. A finite Bessel sum alone is not this diagonal.

**Polynomial coefficient rounding payment:** each regular source polynomial and logarithmic polynomial is rounded to an exact common rational grid. The original coefficient intervals bound the sup norm of the difference on the aperture. The regular-polynomial error is paid in L2 by sqrt(2a); the logarithmic coefficient error is paid by the exact L2 norm of log(a²-x²). This is added to the original source approximation error before the source Gram transfer.

**Frozen scalar source budget:** the DNE25/DNE32 sufficient allocation Gamma_X<=(c/2)C, with c=11/100 in even parity and c=7/50 in odd parity. A coordinate square above (c/2)C_jj disproves this matrix inequality for the fixed frame; it does not disprove whole-aperture positivity.

**Uniform-floor source comparison:** the sufficient Schur estimate Gamma_X<=kappa C using the inherited lower H_F112>=kappa I, kappa=11/25. Failure of this estimate is a failure of the conservative lower-floor substitution, not a sign determination for the actual high inverse response.

**Actual high inverse response:** R_X=B_X* H_F112^-1 B_X, where B_X=P_F112 L_original X and H_F112 is the original positive high restriction. The true Schur matrix is C-R_X, with tested directions and all mixed terms included for a full proof. The general upper bound R_X<=Gamma_X/kappa may be too coarse even when the true Schur matrix is positive.

**Scalar diagonal pilot:** certification of the complete projected source norm for one fixed column in each parity. Passing these two scalar budgets proves neither the other 102 diagonals nor any mixed source entry. A full matrix comparison needs all of those correlations.

**Pilot all-high extension:** the span of the four DNE29 tested columns plus X_0 in each parity, together with every vector of F112. Its retained projection has rank five per parity. The paid native border and two complete source diagonal bounds imply a positive original Schur form on this ten-direction retained span. This adds two directions to DNE29’s eight; it does not cover the other 102 retained directions.
