# RPB108 terminology: native diagonal-tail certificate

- **Native diagonal tail:** high-frequency actual multiplier correction estimated directly relative to the logarithmic weight.
- **Exact-pole retention:** keeping the native rank-two pole form unchanged in the finite approximation.
- **Low-frequency certificate map:** Fourier Taylor approximation only on the retained finite frequency interval.

Definitions accompany first load-bearing use. Rank bounds are not matrix sign, numerical conditioning or runtime guarantees. Historical generic-certificate statements remain unchanged.
