# RPB108 finite archimedean form dictionary

Introduced with NF63, 2026-10-08.

- **Archimedean cutoff N**: retain the first N positive Euler/Laplace summands of the original quarter-line digamma energy, retaining its exact constant m00 and ALL original active primes and both signed pole terms. This produces a bounded lower form Q_N on physical L2; it is not an actual-divisor source form or prime smearing.
- **Cutoff lowest level**: ell_N=inf_{||h||2=1} Q_N(h), over the entire supported physical L2 space. It increases to the original lowest physical level. A finite test matrix gives an upper bound, not this whole-space infimum.
- **Cutoff background**: F_N=L_N I-A_prime+2|cosh(x/2)><cosh(x/2)|, provided L_N exceeds a verified norm bound for the COMPLETE original prime operator.
- **Cutoff compact gain**: the norm of F_N^(-1/2) D_N F_N^(-1/2), where D_N is the sum of the N positive exponential-kernel operators and the original negative sinh pole slot. This is an auxiliary lower-form criterion, distinct from the ORIGINAL complete divisor source gain.

All inverse and compact-gain statements use the entire physical operator and a proved tail bound. No finite prefix is substituted for a whole-space bound.
