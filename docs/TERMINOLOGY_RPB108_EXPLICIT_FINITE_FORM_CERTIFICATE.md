# RPB108 terminology: explicit finite form certificate

- **Finite physical Fourier approximation:** low-frequency Fourier kernel truncated to a Taylor polynomial, a finite-rank physical L2 map whose output is not automatically a supported witness.
- **Finite form certificate:** a finite spectral bound accompanied by the proved native operator-error bound.
- **Exact finite Schur form:** actual finite-dimensional form after eliminating a high complement whose positivity is derived from an error smaller than one.

Definitions accompany first load-bearing use. An approximate eigenvalue near zero is not an exact null certificate. Numerical Gram/native entries remain to be rigorously evaluated. Historical wording is unchanged.
