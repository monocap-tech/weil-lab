# RPB-108 archimedean exterior supplement

Registered before first load-bearing use, 2026-10-01.

- **Gap-truncated archimedean kernel**: the signed half of the pinned Gauss
  cosine density, with |z| replaced by max(gap, |z|). Its value at small
  displacements is an auxiliary continuation, not the actual singular core.
- **Archimedean gap function**: actual convolution of the compact carrier
  with that continuous bounded kernel. Its exterior value equals the
  untruncated Gauss integral and its weighted norm mass genuinely converges.
- **Exterior formula attachment**: equality of the constructed function with
  the explicit exterior integral; this does not assert Fourier/distribution
  identification or the whole-line weak source equation.

Terms are additive. The singular interior core and source representation
remain separate obligations.
