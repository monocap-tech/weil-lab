# CC61 terminology: same-source high completions

Definitions precede the CC61 report and do not change original arithmetic terminology.

The **observed polynomial carrier** in the exact control is E3+H2, with three retained and two measured high vectors. The **fixed source data** comprise the entire physical operator columns on that carrier, their native form block, their complete source-square Gram, the measured-to-unmeasured map K, the compensated source sigma, and an identical high floor kappa. This is stronger than knowing source-square entries alone.

A **same-source high completion** changes only the unmeasured high-to-high block. It leaves every fixed source datum unchanged. The construction is an abstract selfadjoint operator control; it is not a completion allowed by all Weil identities.

The **blind residual coordinate** in this control is a retained vector x with K*sigma x=0. Its true high inverse response depends on an unmeasured diagonal d despite the fixed physical source norm. This is not a full-source null and does not identify an original critical eigenvector.

**Partial-data insufficiency** means that a positivity or contact-exclusion conclusion does not follow from this explicitly listed data package alone. It does not mean that the complete original Weil arithmetic is logically insufficient.
