# RPB108 terminology: actual rough forced inverse

Date: 2026-10-07 UTC. Additive global/F4 definitions.

- Omega=(-a,a) is a sufficiently small actual physical window, with 2a<log 2 so the actual frozen prime set is empty.
- k(s)=exp(-s/2)/(1-exp(-2s)) is the existing actual Euler kernel; m00=m0(0) is the existing quarter-line multiplier value.
- J(x,y)=k(|x-y|)-2cosh((x-y)/2) is the combined off-diagonal interaction kernel of the actual native form in this small window. Its sign is asserted only under the bounds proved in the companion note.
- V_a(x)=m00+integral_(R outside Omega) k(|x-y|)dy+integral_Omega 2cosh((x-y)/2)dy is the exact corresponding multiplication potential.
- An actual rough forced inverse is a canonical actual solution u of Q_a(u,v)=<f,v>_2 for a nonzero nonnegative smooth compact interior forcing f, whose zero extension fails H^(1/2). It is a forced solution, not an actual full-native null vector.
- L_Delta is the external logarithmic Laplacian with angular Fourier symbol 2log|eta|. The factor 1/2 is required to match the native k(s)~1/(2s) singularity; it is not the actual full operator.
- A local torsion barrier beta is the nonnegative zero-exterior solution of L_Delta beta=1 on a sufficiently small edge interval. It is a comparison test supplied by the pinned external theorem, not a source witness.
