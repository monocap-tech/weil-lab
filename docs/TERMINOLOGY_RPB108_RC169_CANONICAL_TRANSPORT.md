# RC169 terminology: native and canonical dual-response transport

The **native reference response** is the RC168 inverse response pulled back by the exact inverse of the source transform WX. This congruence preserves the seven-source relative width 0.450692 and its half-Gram gate. It covers every mixture of the seven specified native carrier vectors.

The **canonical dual response** is the quadratic response of the actual canonical metric inverse L^-1 to the form-dual inputs D times those vectors. RC119–121 prove aP <= L <= P, hence P^-1 <= L^-1 <= a^-1 P^-1, with a=32125/230953. This transports the reference matrix enclosure to a valid canonical response enclosure. It does not construct canonical Riesz vectors or identify these inputs with the original augmentation adjoint range.

The **half-Gram reference gate** is a tested enclosure-width threshold. It is not a prescribed Stage I stopping tolerance. RC123 supplies a requested-tolerance rule; its illustrative targets 10^-6, 10^-12 and 10^-24 are conditional budgets.

The **original response criterion** remains T_Weil Hhat^-1 T_Weil^* <= theta I for theta<1, with Hhat=A_Q+T_Weil^*T_Weil >= eta I. Neither P^-1 nor L^-1 replaces Hhat^-1. Its source map, auxiliary metric, signed action and residual budgets must be paid separately.
