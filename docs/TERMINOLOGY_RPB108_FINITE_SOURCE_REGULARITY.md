# RPB108 finite source regularity terminology

At a nonnegative actual window use H=D_a, full native Riesz operator A, kernel K, finite selected negative analysis R:H->M, and coercive effective covariance G=A+R*R. Let D=I_M-RG^(-1)R* and B=-G^(-1)R*. The **null coefficient space** is E=ker D; B:E->K is the existing exact null reconstruction isomorphism.

The **source regularity flag** is E_j={u in E: the global zero extension of the physical vector Bu belongs to H^j(R)}, for integer j>=0. E_0=E. This concerns global physical Sobolev regularity, not merely interior smoothness or logarithmic Hilbert membership.

A **smooth interior forcing density** represents a selected row against physical tests by an analytic exponential function on [-a,a]. Its logarithmic Hilbert Riesz representative R*u is a different object. Neither that representative nor the effective inverse G^(-1)R*u is presumed globally H1.
