# RC211 terminology

Complete native z_b6 action means the actual supported canonical M=D^-1 L is approximated on the unchanged RC132 native source with every finite and infinite input/output error paid. Endpoint-only coverage is distinct from this full action certificate.

The initial absolute D-norm error upper is 0.000600676; the relative upper is approximately 1.9165%. This does not assert sufficient precision for an expanded inverse gate. The finite endpoint input degree is 512, endpoint output degree 4094, regular input degree 128 and regular output degree 768. The complete negative-r multiplier and omitted native source terms are retained exactly.

RC210's accepted six-source inverse width remains 0.436100. RC211 evaluates no new inverse response. Native t10 action, expanded inverse, odd/source-range and original augmentation are still open. Stage I, RH, F4 and Lean closure remain unclaimed.
