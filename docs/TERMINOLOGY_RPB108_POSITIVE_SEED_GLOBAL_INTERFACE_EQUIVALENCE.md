# RPB108 terminology: positive seed and global interface equivalence

- **Positive seed window:** an explicitly fixed small support window with strict native logarithmic coercivity. The direct seed proved here uses the archimedean error and support uncertainty, without external short-window positivity.
- **All-window full-source unit domination:** ||N_a h||<=||P_a h|| for every a>0 and h in the actual logarithmic domain, with complete multiplicity energy.
- **Endpoint weak-null vector:** Q_a(g,h)=0 for all g in the same D_a; zero diagonal is insufficient.
- **Endpoint-null Gaussian upper property:** every such vector satisfies an eventual polynomial-times-exponential upper bound on its real genuine moving-Gaussian action. Constants may depend on vector and window.
- **Fixed-window strict logarithmic coercivity:** Q_a>=eta_a E_log with eta_a>0 for each fixed a; no uniform-in-a constant is implied.

These notions are used in notes/REFLECTED_PACKET_BRIDGE_108_POSITIVE_SEED_GLOBAL_INTERFACE_EQUIVALENCE_20261004.md. The five global conditions there are proved equivalent, not proved to hold. Selected-background variants are not implicit. Historical terminology remains unchanged.
