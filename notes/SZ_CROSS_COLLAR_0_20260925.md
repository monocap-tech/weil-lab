## 1. Suzuki source pin

Primary source:

- Masatoshi Suzuki, *Weil's quadratic form via the screw function*,
  arXiv:2606.09096v3, 23 September 2026.
- Relevant locations: equations (1.3)–(1.6), Theorem 1.1, Section 8.1,
  equations (8.6)–(8.7), and Section 8.5.

Suzuki defines the continuous even screw kernel (g), the convolution operator

```math
(Gu)(x)=\int_{-\infty}^{\infty} g(x-y)u(y)\,dy,
```

the zero-mean interval space

```math
H_a:=L_0^2(-a,a),
```

and

```math
G_a=P_a G P_a:H_a\to H_a.
```

For the Dirichlet derivative (D=i\,d/dx),

```math
D:H_0^1(-a,a)\overset{\sim}{\longrightarrow}H_a
```

is bijective, and on this regular carrier

```math
Q_W(v)=\langle G_a Dv,Dv\rangle.
```

Suzuki's generalized eigenvalue equation is

```math
G_a u=\lambda K_a u,
\qquad
K_a=(-\Delta_N)^{-1}.
```

At (lambda=0), Suzuki explicitly notes that this reduces to

```math
G_a u=0.
```

This is the coordinate system used below.

## 2. Nested zero-mean carriers

Fix

```math
0<c<b.
```

Let

```math
J_{c,b}:H_c\hookrightarrow H_b
```

be zero extension.

Because (u\in H_c) has zero integral on ((-c,c)), its zero extension still
has zero integral on ((-b,b)), so the embedding is legitimate.

For (u\in H_c), define the global screw potential

```math
F_u(x)
:=
\int_{-c}^{c} g(x-y)u(y)\,dy.
```

Since (u\in L^2(-c,c)\subset L^1(-c,c)) and (g) is continuous,
(F_u) is continuous.

---

## 3. Kernel = constant-potential law

The orthogonal projection onto (H_a=L_0^2(-a,a)) removes the interval
constant. Therefore

```math
G_cu=0
```

if and only if (F_u) is constant on ((-c,c)).

Write that constant as

```math
C_u.
```

Likewise,

```math
G_bJ_{c,b}u=0
```

if and only if the **same** potential (F_u) is constant on all of
((-b,b)).

Hence the Suzuki form of the null-extension question is exactly

```math
\boxed{
F_u\equiv C_u\text{ on }(-c,c)
\quad\stackrel{?}{\Longrightarrow}\quad
F_u\equiv C_u\text{ on a strict larger interval}.
}
```

No new kernel has to be constructed when the interval is enlarged. The
question concerns the old potential generated by the old zero-mean source.

## 4. Exact new-direction space

Let the new collar be

```math
\mathcal C_{c,b}
:=
(-b,-c)\cup(c,b).
```

Inside (H_b), let

```math
N_{c,b}
:=
J_{c,b}(H_c)^\perp.
```

A vector (h\in H_b) lies in (N_{c,b}) exactly when its restriction to
((-c,c)) is constant.

Thus every collar function

```math
\phi\in L^2(\mathcal C_{c,b})
```

has a unique lifted new direction

```math
R_{c,b}\phi
\in N_{c,b}
```

given by

```math
(R_{c,b}\phi)(x)
=
\begin{cases}
-\dfrac{1}{2c}\displaystyle\int_{\mathcal C_{c,b}}\phi(s)\,ds,
& |x|<c,\\[3mm]
\phi(x),
& x\in\mathcal C_{c,b}.
\end{cases}
```

The inner constant is precisely what enforces the global zero-mean condition
in (H_b).

Therefore the genuinely new support directions are canonically parameterized
by collar data. They are **not** merely arbitrary collar-supported zero-mean
functions.

## 5. Exact collar residual

Assume now

```math
0\ne u\in\ker G_c.
```

Define the collar residual

```math
\boxed{
r_{c,b;u}(x)
:=
F_u(x)-C_u,
\qquad
x\in\mathcal C_{c,b}.
}
```

For every (phi\in L^2(\mathcal C_{c,b})),

```math
\boxed{
\left\langle
G_bJ_{c,b}u,
R_{c,b}\phi
\right\rangle_{L^2(-b,b)}
=
\int_{\mathcal C_{c,b}}
r_{c,b;u}(x)\overline{\phi(x)}\,dx.
}
```

Reason: the old-space pairing already vanishes, (F_u=C_u) on the old
interval, and the constant part of (R_{c,b}\phi) cancels exactly against
the collar mean.

Consequently,

```math
\boxed{
G_bJ_{c,b}u=0
\iff
r_{c,b;u}=0
\text{ a.e. on }\mathcal C_{c,b}.
}
```

Because (F_u) is continuous, this is equivalently pointwise vanishing.

This is the exact Suzuki-coordinate realization of the cross-collar block.

## 6. Failure of persistence creates negativity

Still assume (0\ne u\in\ker G_c).

The zero-extended old vector has zero enlarged quadratic value:

```math
\left\langle
G_bJ_{c,b}u,
J_{c,b}u
\right\rangle
=
0.
```

If

```math
r_{c,b;u}\ne0,
```

take

```math
h:=R_{c,b}r_{c,b;u}.
```

Then

```math
\delta
:=
\left\langle G_bJ_{c,b}u,h\right\rangle
=
\|r_{c,b;u}\|_{L^2(\mathcal C_{c,b})}^2
>0.
```

For real (t>0),

```math
\left\langle
G_b(Ju-th),Ju-th
\right\rangle
=
-2t\delta
+
t^2\langle G_bh,h\rangle.
```

For sufficiently small (t>0), the linear cross term dominates, so

```math
\boxed{
\left\langle
G_b(Ju-th),Ju-th
\right\rangle<0.
}
```

Using Suzuki's bijection

```math
D:H_0^1(-b,b)\overset{\sim}{\longrightarrow}H_b,
```

this produces a regular test vector (v_t=D^{-1}(Ju-th)) with

```math
Q_W(v_t)<0.
```

Hence

```math
\boxed{
G_bJ_{c,b}u\ne0
\Longrightarrow
\lambda_b<0.
}
```

This implication is one-way. A negative enlarged ground-state energy does not
exclude coexistence with a zero mode.

## 7. Zero plateau forces persistence

If instead

```math
\lambda_b=0,
```

then the enlarged Weil form is nonnegative. Therefore (G_b) is
nonnegative on (H_b) through the (D)-coordinate realization.

Since (Ju) has zero quadratic value, positivity implies

```math
G_bJu=0.
```

Thus

```math
\boxed{
\lambda_b=0
\Longrightarrow
r_{c,b;u}=0
\Longrightarrow
\text{the old zero mode persists to }b.
}
```

Also, the zero-extended endpoint mode itself gives

```math
\lambda_b\le0
```

for every (b>c) for which this regular (G)-coordinate setup applies.

So after an endpoint zero mode has formed, strict enlargement cannot return
the lowest Weil energy to a positive value.

## 8. Right-collar differential equation

Suzuki gives the distributional kernel

```math
-g''(t)
=
-\frac12\operatorname{Pf}\frac1{|t|}
-(2A+1)\delta(t)
-\sum_{n\ge2}\frac{\Lambda(n)}{\sqrt n}
\bigl(\delta(t-\log n)+\delta(t+\log n)\bigr)
-r''(t).
```

For (x>c), the local delta term does not meet the support of (u), and
(x-y>0) for every (y\in[-c,c]). Formally, on a strict right collar one
therefore obtains

```math
-F_u''(x)
=
-\frac12\int_{-c}^{c}\frac{u(y)}{x-y}\,dy
-
\sum_{n\ge2}\frac{\Lambda(n)}{\sqrt n}
u(x-\log n)
-
\int_{-c}^{c}r''(x-y)u(y)\,dy,
```

with (u) understood as zero outside ([-c,c]); the (u(x+\log n)) terms
vanish automatically for (x>c).

Only finitely many prime-power shifts can meet the compact support for (x)
in a fixed compact collar.

Thus collar persistence forces the exterior equation

```math
\boxed{
F_u''(x)=0
}
```

on an open interval, i.e. a cancellation among

1. an exterior Cauchy/Stieltjes transform of (u);
2. finitely many translated interior samples (u(x-\log n));
3. the smooth archimedean remainder.

This is a more explicit target than the original abstract support-extension
statement.

The displayed differential formula is currently a **formal/distributional
reduction**; regularity/domain details must be audited before theorem status is
assigned to it.
