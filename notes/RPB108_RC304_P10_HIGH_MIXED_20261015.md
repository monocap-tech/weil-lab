# RC304 — native P10 high-output action and six-input polynomial span

**Parent:** RC303 merged `48c47228e88cfdbf66ec983e786b1df5005369a3`.
**Original Weil physical aperture:** B=11/10.
**Rank-317 reference:** 122 even, 195 odd; first omitted even degree 244.
**Standing:** Stage I, F4, RH, true signed inverse, and Lean **OPEN**.

## Research objective

RC303 introduced a **direct input-polynomial** signed prime translation
evaluator and new native P10 original action through output 64.
RC304 extends P10's actual original prime and endpoint projection to
output 2048 using the pinned RC273/RC279 high projection engine, with
every beyond-2048 term paid. It adds the rank-317 physical P10
augmentation only at output degree 10.

The separate mixed source `q=P4-P6/2+P8/3-P10/5` is then
evaluated through all 2049 retained output coefficients by
**linearity across four now individually evaluated full native input
actions**, rather than by a second independent direct high-prime
computation. The distinction is recorded in the certificate.

## Mathematical object and error budget

For every even input degree in `V6=span{P0,P2,P4,P6,P8,P10}`,
the native high-output action consists of a finite profile
`c_{n,d}`, `0<=n<=2048`, the original global D-norm
uncertainty `g_d`, and original infinite-output squared D
tail bound `t_d`.

For the selected reference parameter `lambda` and metric interval
`s_low<=s<=s_high`, its action center includes
`[lambda/(H_d+s_mid)]P_d` only on the corresponding
retained degree. No high original tail is erased.

For each original input source, an upper column error is

`E_d = g_d + sqrt(t_d) + sqrt(m_d(H_d+s_high))*radius_d`.

Given the orthogonal physical D source weights
`w_d=m_d(H_d+s_low)`, Minkowski and Cauchy imply for **all**
vectors y in V6

`||N_new y - hatN_new y||_D <= sum |y_d|E_d <= C6 ||y||_D`,

with `C6^2 >= sum_d E_d^2/w_d` rounded outward.

This is a **uniform operator-action approximation only on the
specified finite six-input span**. It is not a degree-independent
bound on the whole polynomial domain or a proof that V6 is
invariant under N_new.

## Limitations and next frontier

This checkpoint does not execute an independent high-output direct
mixed-polynomial signed prime projector; the high polynomial action
is certified by superposition of pinned input actions.

The inherited RC273 endpoint and prime high-tail estimates are
applied to P10 conditionally on their analytic applicability.
Nothing here proves source-degree-uniform constants for arbitrary
polynomials or permits applying the operator to the infinite
output of a first application. Hence RC292's Chebyshev inverse
recurrence cannot yet be regarded as implemented.

**RC305** should prove or explicitly obstruct degree-indexed
uniform bounds for the original signed prime, archimedean,
pole, endpoint, and output tails, ideally using the direct
polynomial-source interface rather than indefinitely acquiring
isolated Legendre columns.
