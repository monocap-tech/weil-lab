## 1. Global physical gap is impossible in the native infinite carrier

At the native Problem-1 carrier, WD-T28 and the preceding continuity pass give
Hilbert-Schmidt positive/background syntheses.

Hence

```math
S_+S_+^*,
\qquad
S_BS_B^*
```

are trace class, and so

```math
\boxed{
K_B
:=
S_+S_+^*-S_BS_B^*
}
```

is trace class and therefore compact.

Assume the physical carrier is infinite dimensional.

If there were an (eta>0) with

```math
K_B\succeq\eta I,
```

then (K_B) would be boundedly invertible. Consequently

```math
I=K_B^{-1}K_B
```

would be compact.

But the identity on an infinite-dimensional Hilbert space is not compact.

Therefore

```math
\boxed{
K_B\not\succeq\eta I
\quad
\text{for every }\eta>0.
}
```

So the global version of `SZ-BG-GAP` cannot hold on the native
infinite-dimensional Problem-1 carrier.

This is a structural no-go, not an unresolved estimate.

## 2. Selected neutrality does not force strict background contraction

Even before taking the infinite-dimensional limit, the abstract shared budget
allows the background to be saturated while a selected neutral direction
exists elsewhere.

Take

```math
K_+=\mathbb C^2,
\qquad
M=B=\mathbb C,
\qquad
S_+=I_{\mathbb C^2}.
```

Let

```math
X_B z=ze_1,
\qquad
X_M z=ze_2.
```

Then

```math
\|X_B\|=\|X_M\|=1
```

and

```math
X_MX_M^*+X_BX_B^*=I.
```

Thus the joint budget is exactly saturated.

The background residual budget is

```math
R_B
=
I-X_BX_B^*
=
P_{\mathbb C e_2}.
```

After background elimination, the selected channel lies exactly in the
remaining (e_2) direction and is critically screened there.

The full defect is zero:

```math
D_{\rm full}
=
I-P_{e_1}-P_{e_2}
=
0.
```

Hence an attained selected-neutral configuration is compatible with

```math
\boxed{
\|X_B\|=1.
}
```

So Horizon-1 joint-budget geometry does **not** force
(|X_B|<1).

## 3. Background saturation subspace

Now assume the endpoint full screening problem has a joint reduced
factorization

```math
S_M=-S_+X_M,
\qquad
S_B=-S_+X_B,
```

with joint budget

```math
\boxed{
X_MX_M^*+X_BX_B^*\preceq I.
}
```

Define the background saturation space

```math
Z_B
:=
\ker(I-X_BX_B^*).
```

For (a\in Z_B),

```math
X_BX_B^*a=a.
```

Therefore

```math
\|X_B^*a\|^2
=
\langle X_BX_B^*a,a\rangle
=
\|a\|^2.
```

The joint budget gives

```math
\|X_M^*a\|^2
+
\|X_B^*a\|^2
\le
\|a\|^2,
```

hence

```math
\boxed{
X_M^*a=0.
}
```

Thus

```math
\boxed{
Z_B\subseteq\ker X_M^*.
}
```

Equivalently,

```math
\boxed{
\operatorname{Ran}X_M
\perp
Z_B.
}
```

This is the exact shared-budget separation between a fully saturated
background direction and the selected positive compensator.

## 4. Residual budget is strictly positive on the selected-active range

Recall

```math
R_B=I-X_BX_B^*\succeq0.
```

For a positive operator,

```math
\langle R_Ba,a\rangle=0
\iff
a\in\ker R_B
=
Z_B.
```

But

```math
\operatorname{Ran}X_M
\perp Z_B.
```

Therefore every nonzero

```math
a\in\operatorname{Ran}X_M
```

satisfies

```math
\boxed{
\langle R_Ba,a\rangle>0.
}
```

If the selected sector (M) is finite dimensional, then
(operatorname{Ran}X_M) is finite dimensional.

Its unit sphere is compact, so the strictly positive continuous function

```math
a\longmapsto
\langle R_Ba,a\rangle
```

attains a positive minimum there.

Hence there exists

```math
\eta_M>0
```

such that

```math
\boxed{
\langle R_Ba,a\rangle
\ge
\eta_M\|a\|^2
\qquad
(a\in\operatorname{Ran}X_M).
}
```

This is the correct finite selected-sector gap.

## 5. Interpretation

The background is allowed to consume the entire unit budget on some positive
directions.

What the joint budget forbids is simultaneous use of those **same**
fully-saturated directions by the selected screen.

Thus the geometry is not

```text
background has uniform slack everywhere.
```

It is

```text
background saturation is orthogonal to selected positive activity.
```

For a finite selected packet, this orthogonality upgrades to a uniform
positive residual-budget margin on the selected-active range.

That margin survives even though the physical residual covariance itself is
compact and has zero global lower edge.

## 6. Why this does not yet prove collar stability

The selected-active gap above is an endpoint coefficient-space statement.

To transport it to (b>c), one must control:

1. the support-dependent background residual budget
   [
   R_B(b)=I-X_B(b)X_B(b)^*;
   ]
2. the selected active subspace
   [
   W_M(b):=\operatorname{Ran}X_M(b);
   ]
3. their relative position.

The native covariance continuity proved in SZ-BG-COV-CONT-0 does not by itself
control (X_B(b)), because Douglas factorization is sensitive to small
singular directions of (S_+(b)).

Thus the global physical-gap route is closed, but a **relative
coefficient-space stability** problem remains.

## 8. Relation to the neutral selected mode

The attained selected-neutral endpoint does not compete with the saturated
background on the same positive coefficient direction.

At the shared-budget level,

```math
\boxed{
\text{background saturation}
\perp
\text{selected screening range}.
}
```

Therefore simultaneous selected criticality and background criticality are
possible, but they occupy orthogonal coefficient directions in the exact
joint-screened model.

This explains the two-dimensional saturation example and removes the need for
a nonexistent global physical gap.

It does **not** yet show that the two critical sectors remain decoupled after
support enlargement.
