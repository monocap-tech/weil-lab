## Verification design

Emit the compact metadata and deterministic proof proposals once, then eight disjoint bounded Lean shard jobs. Each job builds its original literal row gates using decide +kernel, independently prints each declaration's axioms together with the generic transport theorems, and checks standard axioms only. The complete audit requires all 242 original rows exactly once and the identical metadata and source hashes. The emitted aggregate AllRows.lean is a separate proposed Lean module; this workflow does not compile the aggregate across runners. A full audit success would establish individually certified row truths, not an accepted aggregate declaration or complete hcov on the numerical bank.
