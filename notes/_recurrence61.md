## Objective

Close the scalar parity recurrence from series-60 by finite chamber atomization.

The recurrence does simplify substantially, but the proposed finite-matrix closure is not globally valid.

This pass gives:

1. an exact Schur elimination of the entire tail (q,w);
2. an exact scalar system on the base interval (0,q);
3. only two first-level structural e-chambers;
4. an exact low-head return geometry generated by the old h-step and the k-sheet step;
5. a new short return
   kappa=k-5h;
6. an irrational two-scale return cocycle once e>h.

Thus the parity reduction is real, but for the upper part of the chamber it is a scalar operator cocycle rather than one finite constant matrix.

No extension of ambient prime-channel injectivity is claimed in this pass.

## 19. What this means operationally

The recurrence does not provide unrestricted global translations by h and kappa.

They are partial translations with support gates.

Therefore Section 18 is not, by itself, a dense-orbit theorem for every source point.

What it does prove is enough to invalidate the proposed chamber-independent periodic atomization.

If

e>h,

then:

- the h-return is internal to the lower defect on a nonempty interval;
- the kappa-return is also internal on a nonempty interval.

Hence any common arithmetic mesh or finite periodic residue alphabet invariant under the exact low-head returns would have to make both

h

and

kappa

integer multiples of one common mesh.

Section 18 proves that impossible.

Thus:

boxed:
for e>h,
the exact scalar return geometry is not a finite periodic residue lattice.

The correct upper-chamber object is a partial irrational return cocycle.

This is the low-head return cocycle registered in the terminology file.

### Return-cocycle branch
