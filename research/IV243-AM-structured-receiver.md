## 2. Exact structured prime matrix
Write y=x+2 in [0,L], L=4, alpha=pi/4, e_j(y)=c_j cos(j alpha y), c_0=1/2,c_j=1/sqrt2 (j>0). Let T_s be the sum of zero-extended translations by +/-s, 0<s<L, and P=sum_n a_n T_log(n), a_n=Lambda(n)/sqrt(n). Set theta=alpha*s. Its normalized matrix entries t_jk obey:
- If j+k odd, t_jk=0 (reflection).
- t_00=(L-s)/2.
- t_jj=[(L-s)cos(j theta)-sin(j theta)/(j alpha)]/2 for j>0.
- For same parity j!=k,
  t_jk=2 c_j c_k [k sin(k theta)-j sin(j theta)]/[alpha(j^2-k^2)].
Proof: split signed translation integrals on their exact overlap [0,L-s]. Reflection y->L-s-y transforms one into (-1)^(j+k) times the other, so for same parity it suffices to double the integral of cos(j alpha y) cos(k alpha(y+s)). For distinct j,k integrate derivative of u v'-u'v=(j^2-k^2)alpha^2 uv in the sense that the derivative of the Wronskian equals the RHS. The endpoint values give k alpha sin(k theta)-j alpha sin(j theta) in the even-parity block. Product-to-sum gives diagonal. No cell sampling or periodic replacement of the finite translations. Formula smoke test: independent product-to-sum antiderivative versus Wronskian formula over all 24 shifts and 32x32 modes (24576 entries) agrees to ~6.7e-15 in double precision; non-certifying implementation check only.

For off-diagonals, define d_j=sin(j theta). Then
  [k d_k-j d_j]/(j^2-k^2)=(d_k-d_j)/(2(j-k))-(d_k+d_j)/(2(j+k)).
This yields diagonal-scaled Toeplitz/Hankel products. Set Toeplitz kernel U_jk=1/(j-k) for j!=k, zero on diagonal, Hankel kernel V_jk=1/(j+k) for j+k>0, zero at 0,0; mask by parity (or use separate even/odd blocks). For D=diag(d_j), off-diagonal core = (U D-D U-V D-D V)/2 after excluding diagonal. Restore exact diagonal from above. Normalization uses 2 diag(c_j) on left and diag(c_k)/alpha on right. V diagonal contribution can be removed and corrected in O(M). This is an exact finite matrix representation with O(M) stored scalars per shift and O(M log M) arithmetic operations via zero-padded convolution for length M blocks (Toeplitz kernel indexed differences, Hankel convolution after reversing vector). No FFT rounding certification or implemented fast solver claimed. Same formula gives rectangular mixed blocks using padding, and exact structure does not make the matrix literally sparse.

Gamma Neumann part diagonal. For every retained boundary term kappa=2n+1/2, hyperbolic moments of e_j are explicit:
  integral e_j cosh(kappa x)=c_j*kappa*sinh(2kappa)*(1+(-1)^j)/(kappa^2+(j alpha)^2);
  integral e_j sinh(kappa x)=c_j*kappa*cosh(2kappa)*((-1)^j-1)/(kappa^2+(j alpha)^2).
Integration by parts twice proves these because e_j' endpoints vanish and hyperbolic functions solve u''=kappa^2 u. Pole uses same kappa=1/2 moments. Thus Q_m finite compression consists of a diagonal, 24 structured translation matrices, and at most 2m rank-one corrections (pole absorbed into n=0 coefficient); one per parity at each n. This is a storage/apply reduction, not positivity certificate.
