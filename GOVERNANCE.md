## GitHub-first custody: DEFAULT, NO PER-PASS PERMISSION

Every Weil-Lab investigation, `NF` continuation, mathematical pass, audit, branch pivot, computational test and method STOP is to be **maintained on GitHub as the default workflow**. The owner's standing instruction authorizes additive research commits, branches, draft PRs, scripts, notes, source hashes, reproducibility reports and narrowly scoped CI **without asking again** for transfer permission. A prior `NO_TRANSFER` rule, including one copied into historical conversation/local notes, is **superseded** by this explicit instruction. Do not infer a new transfer prohibition from a chat thread boundary, a missing approval phrase, or a checkpoint label.

For an ordinary `NF` or `continue`: recover the current canonical obligation and actual GitHub head, do the justified research, record its exact standing, commit the new artifacts to a suitable research branch, and link the resulting GitHub commit/PR. If GitHub access genuinely fails, identify the exact untransferred materials and failure instead of presenting them as custodied; reconcile on the next available turn. No detached local-only research as the ordinary stopping state.
